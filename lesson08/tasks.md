# Занятие 08. Задачи для самостоятельного решения

Каждое решение оформляется как функция с указанной сигнатурой. Функция возвращает итератор или генератор и не использует `input` или `print`.

## Easy 1. Завершённые операции

Реализуйте ленивый фильтр:

```python
from collections.abc import Iterable, Iterator

def iter_completed(
    operations: Iterable[dict],
) -> Iterator[dict]:
    ...
```

Функция должна выдавать только записи со значением `status == "completed"`, сохраняя исходный порядок.

Пример:

```python
operations = [
    {"id": "o-1", "status": "completed"},
    {"id": "o-2", "status": "pending"},
    {"id": "o-3", "status": "completed"},
]
result = iter_completed(operations)
assert iter(result) is result
assert [row["id"] for row in result] == ["o-1", "o-3"]
```

Ограничения:

- функция принимает любой `Iterable`, а не только список;
- вход может содержать до `1_000_000` записей;
- создавать список всех результатов внутри функции нельзя.

Критерии проверки:

- используется `yield` или генераторное выражение;
- до первого `next()` вход не обходится;
- дополнительная память не растёт с числом операций.

## Easy 2. Значимые строки отчёта

Реализуйте:

```python
from collections.abc import Iterable, Iterator

def iter_report_lines(lines: Iterable[str]) -> Iterator[str]:
    ...
```

Удаляйте пробелы по краям, пропускайте пустые строки и строки, которые после удаления пробелов начинаются с `#`.

Пример:

```python
source = ["  income;1200  ", "", " # comment", "tax;300\n"]
assert list(iter_report_lines(source)) == ["income;1200", "tax;300"]
```

Ограничения:

- вход может быть файловым объектом;
- каждая исходная строка просматривается один раз;
- нельзя сначала преобразовывать весь вход в список.

Критерии проверки:

- порядок значимых строк сохраняется;
- пустые строки и комментарии не выдаются;
- результат вычисляется лениво.

## Easy 3. Пакеты для отправки

Реализуйте:

```python
from collections.abc import Iterable, Iterator
from typing import TypeVar

T = TypeVar("T")

def iter_batches(items: Iterable[T], size: int) -> Iterator[list[T]]:
    ...
```

Выдавайте элементы пакетами длины `size`. Последний пакет может быть короче. При `size <= 0` поднимите `ValueError`.

Примеры:

```python
assert list(iter_batches(range(7), 3)) == [[0, 1, 2], [3, 4, 5], [6]]
assert list(iter_batches([], 3)) == []
```

Ограничения:

- вход может быть одноразовым итератором без `len()` и индексов;
- одновременно в памяти хранится не более одного собираемого пакета;
- `list(items)` запрещён.

Критерии проверки:

- каждый элемент выдаётся ровно один раз;
- порядок сохраняется;
- дополнительная память `O(size)`.

## Medium 1. Поток транзакций из строк

Строки имеют формат `id;category;amount`, например `t-17;food;1250`. Пустые строки и комментарии обрабатываются как в Easy 2.

Реализуйте:

```python
from collections.abc import Iterable, Iterator

def iter_transactions(
    lines: Iterable[str],
    min_amount: int = 0,
) -> Iterator[dict]:
    ...
```

Лениво выдавайте словари транзакций, сумма которых не меньше `min_amount`:

```python
lines = [
    "# exported report\n",
    "t-1;food;900\n",
    "t-2;taxi;300\n",
    "t-3;rent;45000\n",
]
assert list(iter_transactions(lines, 800)) == [
    {"id": "t-1", "category": "food", "amount": 900},
    {"id": "t-3", "category": "rent", "amount": 45000},
]
```

Некорректная значимая строка должна приводить к `ValueError` в момент, когда обход дошёл до неё. Сообщение должно содержать номер исходной строки, начиная с 1.

Ограничения:

- `0 <= min_amount`;
- вход может не помещаться в память;
- строка обрабатывается один раз;
- промежуточные списки всех строк или транзакций запрещены.

Критерии проверки:

- проверяется ровно три поля и целая неотрицательная сумма;
- номер ошибки относится к исходному входу, включая комментарии и пустые строки;
- до потребления генератора ошибки во входе не возникают;
- дополнительная память `O(1)` без учёта одной текущей записи.

## Medium 2. Слияние журналов событий

Два источника лениво выдают словари, уже упорядоченные по целому полю `timestamp`.

```python
from collections.abc import Iterable, Iterator

def merge_events(
    left: Iterable[dict],
    right: Iterable[dict],
) -> Iterator[dict]:
    ...
```

Выдайте единый поток по возрастанию времени. При равном `timestamp` событие из `left` должно идти раньше события из `right`.

Пример:

```python
left = iter([
    {"id": "bank-1", "timestamp": 10},
    {"id": "bank-2", "timestamp": 20},
])
right = iter([
    {"id": "api-1", "timestamp": 20},
    {"id": "api-2", "timestamp": 30},
])
assert [event["id"] for event in merge_events(left, right)] == [
    "bank-1", "bank-2", "api-1", "api-2"
]
```

Ограничения:

- суммарный вход может быть очень большим;
- повторная сортировка запрещена;
- у итераторов нет `len()` и индексов;
- разрешено держать в памяти не более одного текущего события от каждого источника.

Критерии проверки:

- каждый источник просматривается один раз;
- время `O(N + M)`, дополнительная память `O(1)`;
- пустой источник и равные временные отметки обработаны явно;
- результат остаётся ленивым.
