# Справочные материалы

К этим материалам можно обращаться при самостоятельной работе и подготовке группового проекта. Они доступны отдельно от занятий; упражнения внутри справочника помогают освоить инструменты на небольшом учебном проекте.

## Git и структура Python-проекта

[Из функции в проект](python-project.ipynb) — руководство, перенесённое из прежнего семинара 4.

Внутри:

- Git: создание репозитория, `.gitignore`, коммиты, ветки и разрешение конфликтов;
- виртуальное окружение и зависимости;
- модули, пакеты, импорты и `src`-layout;
- `pyproject.toml` и editable-установка;
- разделение вычислений, файлового ввода и CLI;
- console entry point, Ruff и smoke-тесты;
- README и воспроизводимый запуск из чистого клона.

Команды выполняются в отдельном учебном репозитории. Требуется Python 3.14; подготовка окружения для ноутбуков описана в [основном README](../README.md#запуск).

[Дополнительные упражнения](python-project-tasks.md) помогают закрепить работу с Git, пакетами и CLI. [Семинар 4](../lesson04/seminar.ipynb) и [домашняя работа 4](../lesson04/tasks.md) посвящены функциям и рекурсии.
