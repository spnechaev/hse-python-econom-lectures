# Занятие 03. Задачи для самостоятельного решения

Каждое решение оформляется как функция с указанной сигнатурой. Функция возвращает результат и не использует `input` или `print`.

## Easy 1. Первый индекс

Реализуйте линейный поиск:

```python
def linear_search(values: list[int], target: int) -> int:
    ...
```

Верните индекс первого элемента, равного `target`. Если такого элемента нет, верните `-1`.

Примеры:

```python
linear_search([], 5) == -1
linear_search([7, 2, 7], 7) == 0
linear_search([1, 3, 5], 4) == -1
```

Ограничения:

- `0 <= len(values) <= 100_000`;
- значения могут повторяться;
- список не обязан быть отсортирован.

Критерии проверки:

- список просматривается слева направо не более одного раза;
- возвращается первый индекс;
- пустой список и отсутствие цели обработаны корректно;
- временная сложность `O(N)`, дополнительная память `O(1)`.

## Easy 2. Число вхождений

Реализуйте функцию:

```python
def count_occurrences(values: list[int], target: int) -> int:
    ...
```

Верните количество элементов, равных `target`. Используйте один линейный проход.

Примеры:

```python
count_occurrences([], 1) == 0
count_occurrences([1, 2, 1, 1], 1) == 3
count_occurrences([4, 5, 6], 0) == 0
```

Ограничения:

- `0 <= len(values) <= 100_000`;
- `-10**9 <= target, values[i] <= 10**9`.

Критерии проверки:

- выполняется один проход по списку;
- исходный список не изменяется;
- временная сложность `O(N)`, дополнительная память `O(1)`.

## Easy 3. Проверка упорядоченности

Реализуйте функцию:

```python
def is_sorted_non_decreasing(values: list[int]) -> bool:
    ...
```

Верните `True`, если каждый следующий элемент не меньше предыдущего. Пустой список и список из одного элемента считаются отсортированными.

Примеры:

```python
is_sorted_non_decreasing([]) is True
is_sorted_non_decreasing([1, 1, 3, 8]) is True
is_sorted_non_decreasing([1, 4, 2]) is False
```

Ограничения:

- `0 <= len(values) <= 100_000`;
- не создавать отсортированную копию списка.

Критерии проверки:

- сравниваются соседние элементы;
- функция завершает работу после первого нарушения;
- временная сложность в худшем случае `O(N)`, дополнительная память `O(1)`.

## Medium 1. Первое вхождение бинарным поиском

Реализуйте функцию для отсортированного по неубыванию списка:

```python
def binary_search_first(values: list[int], target: int) -> int:
    ...
```

Верните индекс первого элемента, равного `target`. Если цели нет, верните `-1`. Линейный просмотр списка использовать нельзя.

Примеры:

```python
binary_search_first([], 3) == -1
binary_search_first([1, 2, 2, 2, 5], 2) == 1
binary_search_first([1, 3, 5, 7], 4) == -1
```

Ограничения:

- `0 <= len(values) <= 1_000_000`;
- список отсортирован по неубыванию;
- значения могут повторяться.

Критерии проверки:

- границы поиска сужаются примерно вдвое на каждом шаге;
- найденное равенство не завершает поиск слишком рано;
- пустой список и крайние позиции обработаны корректно;
- временная сложность `O(log N)`, дополнительная память `O(1)`.

## Medium 2. Число вхождений в отсортированном списке

Реализуйте функцию:

```python
def count_in_sorted(values: list[int], target: int) -> int:
    ...
```

Список отсортирован по неубыванию. Найдите левую границу элементов, не меньших `target`, и левую границу элементов, больших `target`. Разность границ равна числу вхождений. Линейный просмотр запрещён.

Примеры:

```python
count_in_sorted([], 2) == 0
count_in_sorted([1, 2, 2, 2, 4], 2) == 3
count_in_sorted([1, 3, 5], 2) == 0
```

Ограничения:

- `0 <= len(values) <= 1_000_000`;
- список отсортирован по неубыванию.

Критерии проверки:

- используются два бинарных поиска границы;
- решение корректно при цели меньше всех и больше всех элементов;
- временная сложность `O(log N)`, дополнительная память `O(1)`.

## Hard 1. Минимальная производительность

Производственная линия должна последовательно обработать партии работ. За один час она обрабатывает не более одной партии и выполняет до `rate` единиц работы из неё. Если партия не закончена, следующий час снова тратится на ту же партию. Для партии объёма `work` потребуется `ceil(work / rate)` часов.

Реализуйте функцию:

```python
def minimum_rate(workloads: list[int], hours: int) -> int:
    ...
```

Верните минимальную целую положительную производительность, с которой все партии можно обработать не более чем за `hours` часов.

Примеры:

```python
minimum_rate([3, 6, 7, 11], 8) == 4
minimum_rate([30, 11, 23, 4, 20], 5) == 30
minimum_rate([30, 11, 23, 4, 20], 6) == 23
```

Ограничения:

- `1 <= len(workloads) <= 100_000`;
- `1 <= workloads[i] <= 10**9`;
- `hours >= len(workloads)`;
- использовать вещественное деление для округления вверх не требуется.

Критерии проверки:

- определён монотонный предикат «данной производительности достаточно»;
- поиск выполняется по диапазону от `1` до `max(workloads)`;
- часы для партии считаются целочисленно, например `(work + rate - 1) // rate`;
- временная сложность `O(N log M)`, где `M = max(workloads)`;
- линейный перебор всех значений производительности не используется.
