# Занятие 03. Задачи для самостоятельного решения

> **Домашняя работа.** В материалах курса приведены **предполагаемые списки домашних задач**. Домашние задания нужно решать и сдавать в **Яндекс.Контесте**. Актуальный список задач, условия и требования к оформлению находятся в Контесте. **При расхождениях информация в Контесте имеет приоритет.** Ссылки на контесты публикуются на **вики курса**.

Три задачи Easy — на повторение условий, циклов и функций. Две задачи Medium требуют более сложной обработки последовательностей. Необязательная задача Hard — на самостоятельную алгоритмическую идею.

Каждое решение оформляется как функция с указанной сигнатурой. Все данные передаются через параметры. Функции возвращают результат, не используют `input` и `print` и не изменяют входные списки. Входные данные соответствуют ограничениям из условий; проверять их типы не нужно.

К каждому решению добавьте свои проверки и короткое объяснение:

- что вы считаете размером входа;
- сколько раз выполняется основная операция;
- каковы временная сложность, память для результата и вспомогательная память.

В задачах Easy оцените сложность своего решения самостоятельно. В задачах Medium и Hard нужно также уложиться в указанную оценку времени и объяснить, почему решение работает. Для анализа считаем арифметические операции и сравнения чисел за `O(1)`, без учёта стоимости работы с очень большими целыми. Стоимость встроенных функций и операций с коллекциями учитывайте.

## Easy 1. Сколько чётных

Реализуйте функцию:

```python
def count_even(values: list[int]) -> int:
    ...
```

Верните количество чётных чисел в списке. Чётное число делится на 2 без остатка. Ноль и отрицательные чётные числа тоже учитываются. Если список пуст, верните `0`.

Примеры:

```python
count_even([3, 8, 0, -4, 7]) == 3
count_even([1, 3, 5]) == 0
count_even([2, 2, 2]) == 3
count_even([-2]) == 1
count_even([]) == 0
```

Ограничения:

- `0 <= len(values) <= 100_000`;
- `-10**9 <= values[i] <= 10**9`;
- используйте цикл и условие; не используйте `sum`, `count`, `filter` и готовые функции подсчёта.

Критерии проверки:

- каждое вхождение чётного числа учитывается отдельно;
- нечётные числа не влияют на ответ;
- результат имеет тип `int`.

При оценке сложности обозначьте длину списка через `n`.

## Easy 2. Квадраты чисел

Реализуйте функцию:

```python
def squares(values: list[int]) -> list[int]:
    ...
```

Верните новый список, в котором каждый элемент равен квадрату соответствующего элемента исходного списка. Сохраните порядок и повторы. Для пустого списка верните новый пустой список.

Примеры:

```python
squares([3, -2, 0, 3]) == [9, 4, 0, 9]
squares([-1]) == [1]
squares([0, 1]) == [0, 1]
squares([]) == []
```

Ограничения:

- `0 <= len(values) <= 100_000`;
- `-10**9 <= values[i] <= 10**9`;
- используйте цикл `for`; не используйте `map`.

Критерии проверки:

- длина результата совпадает с длиной входного списка;
- возвращается новый список, даже если значения после возведения в квадрат не изменились;
- входной список сохраняется.

При оценке сложности обозначьте длину списка через `n`. Отдельно укажите память для результата.

## Easy 3. Сколько цифр

Реализуйте функцию:

```python
def count_digits(number: int) -> int:
    ...
```

Верните количество цифр в десятичной записи неотрицательного целого числа. У числа `0` одна цифра.

Примеры:

```python
count_digits(0) == 1
count_digits(7) == 1
count_digits(10) == 2
count_digits(5072) == 4
count_digits(10000) == 5
```

Ограничения:

- `0 <= number <= 10**18`;
- используйте `while` и целочисленные арифметические операции;
- не превращайте число в строку или коллекцию и не используйте логарифмы.

Критерии проверки:

- нули внутри числа и в конце его записи учитываются;
- случай `number == 0` обработан корректно;
- результат имеет тип `int`.

Оцените время через количество цифр `d`, затем выразите оценку через значение `number` для положительных чисел.

## Medium 1. Сжать повторы подряд

Реализуйте функцию:

```python
def compress_runs(values: list[int]) -> list[tuple[int, int]]:
    ...
```

Замените каждую группу подряд идущих одинаковых чисел одним кортежем `(число, количество повторений)`. Верните список таких кортежей в исходном порядке групп.

Одинаковые числа, разделённые другими значениями, относятся к разным группам. Например, в `[3, 3, 2, 3]` две отдельные группы троек. Пустому списку соответствует пустой результат.

Примеры:

```python
compress_runs([3, 3, 2, 3]) == [(3, 2), (2, 1), (3, 1)]
compress_runs([5, 5, 5]) == [(5, 3)]
compress_runs([1, 2, 3]) == [(1, 1), (2, 1), (3, 1)]
compress_runs([0, 0, -2, -2, -2]) == [(0, 2), (-2, 3)]
compress_runs([7]) == [(7, 1)]
compress_runs([]) == []
```

Ограничения:

- `0 <= len(values) <= 100_000`;
- `-10**9 <= values[i] <= 10**9`;
- требуемое время — `O(n)`, где `n` — длина списка;
- не используйте готовые функции группировки, в том числе `itertools.groupby`.

Критерии проверки:

- каждая группа описана ровно одним кортежем;
- разделённые группы одинаковых чисел не объединяются;
- количество повторений в каждом кортеже положительное;
- сохраняются первая и последняя группы;
- входной список не изменяется.

Оцените память через длину входа `n` и количество групп `r`.

## Medium 2. Суммы на отрезках

Реализуйте функцию:

```python
def range_sums(
    values: list[int], queries: list[tuple[int, int]]
) -> list[int]:
    ...
```

Дан список целых чисел и несколько запросов. Каждый запрос — кортеж `(left, right)` с индексами начала и конца отрезка. Индексы начинаются с нуля. **Обе границы включаются**: для запроса `(1, 3)` нужно сложить элементы с индексами `1`, `2` и `3`.

Верните список сумм в порядке запросов. Один запрос может повторяться. Если запросов нет, верните пустой список. Между запросами исходные значения не меняются.

Примеры:

```python
range_sums([3, -1, 4, 2], [(0, 1), (1, 3), (2, 2)]) == [2, 5, 4]
range_sums([3, -1, 4, 2], [(0, 3), (0, 3)]) == [8, 8]
range_sums([-5, -2, -3], [(0, 2), (1, 1)]) == [-10, -2]
range_sums([7], [(0, 0)]) == [7]
range_sums([1, 2, 3], []) == []
range_sums([], []) == []
```

Ограничения:

- `0 <= len(values) <= 100_000`;
- `0 <= len(queries) <= 100_000`;
- `-10**9 <= values[i] <= 10**9`;
- каждый запрос корректен: `0 <= left <= right < len(values)`;
- если `values` пуст, список запросов тоже пуст;
- требуемое общее время — `O(n + q)`, где `n = len(values)`, `q = len(queries)`; сюда входит вся подготовка данных и обработка всех запросов.

Критерии проверки:

- возвращается один ответ на каждый запрос в исходном порядке;
- корректно обрабатываются отрезок из одного элемента и весь список;
- отрицательные числа и повторяющиеся запросы учитываются;
- оба входных списка сохраняются;
- общая временная сложность соответствует требованию.

Отдельно оцените память для ответов и вспомогательных данных через `n` и `q`.

## Hard 1. Поровну нулей и единиц

Необязательная задача на идею.

Реализуйте функцию:

```python
def longest_balanced_segment(values: list[int]) -> int:
    ...
```

Список состоит только из нулей и единиц. Верните длину самого длинного **непрерывного отрезка**, в котором нулей и единиц поровну. Отрезок состоит из соседних элементов исходного списка; переставлять элементы или пропускать их внутри отрезка нельзя.

Например, в `[0, 0, 1, 0, 1, 1, 1]` подходят первые шесть элементов: в них три нуля и три единицы. Ответ — `6`.

Если подходящего непустого отрезка нет, верните `0`. Для пустого списка ответ тоже равен `0`.

Примеры:

```python
longest_balanced_segment([0, 0, 1, 0, 1, 1, 1]) == 6
longest_balanced_segment([0, 1, 0]) == 2
longest_balanced_segment([1, 1, 0, 0]) == 4
longest_balanced_segment([1, 1, 1]) == 0
longest_balanced_segment([0]) == 0
longest_balanced_segment([]) == 0
```

Ограничения:

- `0 <= len(values) <= 100_000`;
- каждый элемент равен `0` или `1`;
- требуемое время — `O(n)` в среднем, где `n` — длина списка;
- допускается `O(n)` вспомогательной памяти.

Критерии проверки:

- найден именно непрерывный отрезок;
- возвращается максимальная возможная длина;
- исходный список не изменяется;
- решение укладывается в требуемую сложность;
- приведено объяснение, почему алгоритм находит самый длинный подходящий отрезок.
