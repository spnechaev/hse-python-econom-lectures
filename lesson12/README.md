## Какую задачу решаем

Магазин показывает два приятных показателя: продано за вычетом возвратов вдвое больше вещей, выручка выросла на 12,7%. В следующем периоде предлагают увеличить рекламу. Нужно решить, достаточно ли этих чисел для согласования бюджета.

Работаем с тремя CSV: события продаж и возвратов, справочник товаров, реклама по месяцам и каналам. В выгрузке есть точные повторы, конфликтующие версии события, неизвестный товар, неверная дата и пропущенное количество. Это синтетический учебный кейс: его можно целиком проверить и повторить без сети.

Разбор устроен как последовательная проверка решений. Сначала получаем неправдоподобно огромные рекламные расходы из кода без ошибки. Исправляем соединение — и обнаруживаем, что реальное ухудшение результата осталось. Проверяем состав продаж, затем предложение скидки и только после этого пишем вывод. pandas нужен сразу для работы с выгрузкой; NumPy появляется, когда приходится сравнивать варианты скидок и объёмов. Matplotlib показывает проверенные результаты.

Отдельно сравним скидки и объёмы продаж в NumPy. Это расчёт последствий заданных предположений; реакцию покупателей таблица сама не предсказывает.

## Результаты обучения

После занятия студент умеет:

- различать список, `ndarray`, `Series` и `DataFrame`, читать `shape` и `dtype`;
- читать CSV с нужным разделителем и кодировкой, сохраняя текстовые идентификаторы;
- выбирать строки и столбцы через `.loc`, `.iloc` и маски;
- отличать точный повтор от разных позиций заказа и конфликта идентификатора;
- проверять числа и даты, сохранять журнал отклонённых строк;
- соединять таблицы с `validate` и `indicator`, замечать размножение сумм;
- группировать данные на нужном уровне и учитывать расходы канала без продаж;
- различать пропуск и известный ноль, сохранять точность целых сумм;
- считать средневзвешенную цену и отличать её от индекса цен;
- строить понятный график и таблицу сценариев через broadcasting;
- учитывать выравнивание pandas по меткам, Copy-on-Write и срезы NumPy;
- сохранять результат и формулировать вывод с понятными ограничениями.

В конце лекции — пример экзаменационного вопроса о соединении продаж с рекламными расходами.

## Запуск

Целевая версия — Python 3.14. Нужны NumPy 2.4+, pandas 3.x и Matplotlib 3.11+. Установите зависимости в окружении курса:

```bash
python -m pip install -r requirements.txt
```

После установки перезапустите ядро. Во время выполнения сеть не нужна. Откройте ноутбук из корня репозитория или каталога `lesson12` и запускайте ячейки сверху вниз. Входные файлы не перезаписываются; экспорт показан через текстовый поток в памяти.

Для запуска отдельно от репозитория сохраните рядом с ноутбуком каталог `data` с тремя CSV и `expected.json`. Для просмотра схем нужен также каталог `assets`; вводный дашборд и итоговый график уже встроены в ноутбук как вложения. В Colab можно загрузить тот же каталог данных в рабочую папку.

## Семинар

Пять задач: расчёт по массивам NumPy, маска корректных строк, свод по каналам, безопасное присоединение справочника и результат после рекламы. Входные таблицы и массивы передаются функциям; внешних файлов не нужно.

В ноутбуке оставлены заготовки без решений и проверки. Вызовы проверок закомментированы: исходный ноутбук выполняется, а готовую задачу проверяют отдельно. Правила пропусков, типов, порядка строк и сохранности входов заданы явно.
