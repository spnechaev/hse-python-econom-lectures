## 3. Разобрать число, затем проверить

```python
units = pd.to_numeric(raw["units"], errors="coerce")
valid = units.notna() & (units > 0) & (units % 1 == 0)
accepted = raw.loc[valid.fillna(False)].copy()
rejected = raw.loc[~valid.fillna(False)].copy()
```

Здесь проверено только количество. Дата, цена и ключи требуют своих условий. Превращение ошибки в пропуск через `errors="coerce"` само по себе ничего не исправляет. Запишите номер исходной строки и причину отказа; сохраните контроль числа исключённых строк.

`&`, `|` и `~` работают с масками. Для изменения исходной таблицы используйте одно присваивание через `.loc[mask, "column"] = value`; для независимого набора берите `.copy()`.

## 4. Соединить по проверенному ключу

```python
joined = accepted.merge(
    catalog, on="product_id", how="left",
    validate="many_to_one", indicator=True,
)
print(joined["_merge"].value_counts())
```

До соединения проверьте непустые и уникальные ключи справочника. `left_only` требует решения, а не молчаливой потери строки. Одинаковые пропуски в ключах pandas может соединить между собой.

`validate` проверяет число совпадений. Он не знает, что месячный рекламный бюджет нельзя сложить по каждой товарной строке. Сначала приведите обе таблицы к согласованному уровню: например, месяц и канал.

## 6. Не потерять деньги из-за пропуска

Сначала определите, означает ли отсутствие строки известный ноль. Расход канала без продаж существует. Отсутствующий расход нельзя объявить нулевым.

При внешнем соединении целые суммы можно хранить в nullable-типе `Int64`: он допускает и целое, и пропуск без перехода во `float`. Заглавная `I` значима. После проверенного заполнения известных нулей можно вернуться к `int64`.

```python
amounts = pd.Series([pd.NA, pd.NA], dtype="Int64")
print(amounts.sum(min_count=1))  # <NA>, данных для суммы нет
```

Для денег используйте целые копейки или заранее выбранную точную арифметику. У `np.int64` есть предел; проверьте, помещаются ли произведения и суммы. Большой Python `int` и число в массиве — разные случаи.

## 7. Посчитать «что, если»

```python
price, cost = 40_000, 32_000
discounts = np.array([0, 5, 10])

new_price = price * (100 - discounts[:, None]) // 100
margin = quantities[None, :] * (new_price - cost)
```

Строка — скидка, столбец — объём. Это следствия поставленных условий. Чтобы назвать таблицу прогнозом, нужны основания для выбранного спроса. Следите за `shape`, единицами и правилами округления.
