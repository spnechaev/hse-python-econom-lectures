## Результаты обучения

После занятия студент умеет:

- формулировать ключ и направление сортировки;
- различать `sorted()` и `list.sort()`;
- объяснять и использовать стабильность;
- реализовывать стабильную сортировку вставками;
- реализовывать слияние и merge sort;
- объяснять устройство двоичной кучи и реализовывать heapsort;
- объяснять средний и худший случаи quicksort;
- реализовывать radix sort для неотрицательных целых чисел;
- объяснять факториальное ожидаемое время bogosort;
- выбирать алгоритм по размеру, структуре входа и памяти;
- использовать встроенный Timsort для прикладного кода;
- проверять сортировку на порядке, сохранности элементов и стабильности.

## Самостоятельная работа

Основной набор состоит из трёх задач Easy и двух задач Medium. Необязательная Hard-задача использует слияние для подсчёта инверсий.
