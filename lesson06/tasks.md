## Easy 1. Очередь заявок

Заявка — словарь с уникальным строковым `id`, целочисленным `priority` и временем `created_at` в формате `HH:MM` одного дня. Верните новый список: сначала больший приоритет, внутри одного приоритета — более раннее время. При полном равенстве этих полей сохраните исходный порядок.

```python
def order_requests(requests: list[dict]) -> list[dict]:
    ...
```

Пример:

```python
requests = [
    {"id": "a", "priority": 1, "created_at": "09:00"},
    {"id": "b", "priority": 3, "created_at": "10:00"},
    {"id": "c", "priority": 3, "created_at": "08:30"},
    {"id": "d", "priority": 3, "created_at": "08:30"},
]
assert [item["id"] for item in order_requests(requests)] == ["c", "d", "b", "a"]
assert order_requests([]) == []
```

Ограничения: до 100 000 заявок, приоритет от 0 до 100. Используйте `sorted()` с `key`.

Критерии: оба направления соблюдены, равные ключи сохраняют порядок, вход не изменён; время — `O(n log n)` в худшем случае.

```python

    ...
```

Примеры:

```python

assert merge_sort([7]) == [7]
assert merge_sort([5, 2, 4, 2]) == [2, 2, 4, 5]
```

## Medium 1. Таблица результатов

У участника есть уникальный строковый `id`, непустое имя `name` и результат `score`. Результат — строка из десятичных цифр (возможны ведущие нули) или `None`, если участник ещё не выступил.

3. При равных результатах имена сравниваются по возрастанию без учёта регистра с помощью `casefold()`. Это правило действует и для участников без результата.
4. Если все перечисленные признаки равны, сохраняется исходный порядок.

```python
def rank_participants(participants: list[dict]) -> list[dict]:
    ...
```

Пример:

```python
participants = [
```

Критерии: выполнены все четыре правила; `None` не смешивается с нулевым результатом; значения и порядок входа не изменены; время — `O(n log n)` при указанных ограничениях на строки.

## Hard 1. Поразрядная сортировка — необязательная задача

Самостоятельно реализуйте поразрядную сортировку **LSD radix sort** для неотрицательных целых чисел. Верните новый список по возрастанию, сохранив все повторы. Исходный список изменять нельзя.

Идея: сначала упорядочьте числа по цифре единиц, затем по цифре десятков, затем сотен и так далее. Недостающие слева цифры считайте нулями. Каждый проход должен быть **стабильным**: числа с одинаковой текущей цифрой сохраняют порядок предыдущего прохода. Поэтому уже обработанные младшие разряды продолжают определять порядок при равенстве старших.

Например:

```text
Исходный список:  [21, 12, 11, 22]
По единицам:     [21, 11, 12, 22]   # сначала цифра 1, затем 2
По десяткам:     [11, 12, 21, 22]   # внутри десятка порядок единиц сохранился
```

Для одного прохода можно завести десять списков-корзин, по одному для каждой цифры. Просмотрите текущий список слева направо, добавьте каждое число в соответствующую корзину, затем соберите корзины в порядке от 0 до 9. Такое распределение сохраняет порядок внутри каждой корзины. Другой допустимый вариант — стабильная сортировка подсчётом по текущей цифре.

Цифру разряда извлекайте целочисленными операциями: для единиц делитель равен 1, для десятков — 10, для сотен — 100. Продолжайте до старшего разряда максимального числа; отдельно продумайте пустой список и список из нулей. Числа с плавающей точкой не нужны.

```python
def radix_sort(values: list[int]) -> list[int]:
    ...
```

Примеры:

```python
assert radix_sort([]) == []
assert radix_sort([0, 0]) == [0, 0]
assert radix_sort([21, 12, 11, 22]) == [11, 12, 21, 22]
assert radix_sort([80, 8, 800, 0, 80]) == [0, 8, 80, 80, 800]
assert radix_sort([170, 45, 75, 90, 802, 24, 2, 66]) == [2, 24, 45, 66, 75, 90, 170, 802]
assert radix_sort([1_000_000_000, 10, 1, 100, 0]) == [0, 1, 10, 100, 1_000_000_000]

values = [12, 3, 12]
result = radix_sort(values)
assert result == [3, 12, 12]
assert values == [12, 3, 12]
assert result is not values
```

Ограничения: до 100 000 чисел, каждое от 0 до 10⁹ включительно. Используйте только стандартную библиотеку. Требуется именно LSD radix sort со стабильными проходами по десятичным цифрам; `sorted()` и `.sort()` запрещены. Отрицательных чисел во входе нет.

Критерии: верный порядок, сохранение повторов, новый список и неизменность входа; время — `O(d · (n + b))`, где `n` — длина списка, `b = 10`, а `d` — число десятичных разрядов максимума (для пустого списка и нулевого максимума примите `d = 1`). Общая дополнительная память, **включая результат**, — `O(n + b)`: корзины или счётчики переиспользуются на следующих проходах, результаты всех проходов хранить не нужно. При данных ограничениях `d <= 10`; без ограничения на величину чисел число проходов не является константой.
