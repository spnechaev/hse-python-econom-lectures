# Материалы курса по Python

Курс сочетает лекции, практические и справочные семинары, домашние задания и групповой проект. Утверждённая структура курса на 14 занятий приведена в [программе курса](COURSE_PLAN.md).

Учебные материалы собраны в Jupyter Notebook. Существующие ноутбуки постепенно приводятся в соответствие с новой программой: от модели данных Python и базовых алгоритмов до веб-разработки, асинхронности и баз данных.

## Запуск

Рекомендуется Python 3.11 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab
```

Некоторые примеры семинаров 09 и 10 выполняют HTTP-запросы и требуют подключения к интернету. Все остальные материалы должны работать локально.

Кодовые ячейки размечены тегами:

- `demo` — исполняемый пример;
- `exercise` — заготовка, которую должен дописать студент;
- `network` — пример требует интернета;
- `jupyter-only` — используется возможность Jupyter, например top-level `await`;
- `requires-nb-mypy` — требуется расширение `nb-mypy`;
- `slow` и `blocking-demo` — намеренно медленный пример блокирующего кода.

## Правила оформления материалов

- Актуальные сроки сдачи и правила штрафов хранятся в отдельном файле [`DEADLINES.md`](DEADLINES.md), а не в ноутбуках.
- Перед публикацией у всех ячеек очищаются результаты и номера запусков.
- Намеренно ошибочные примеры должны быть явно помечены в тексте.
- В конце каждой лекции есть раздел «Неожиданно, но по правилам»: короткие примеры контринтуитивного поведения, которое следует из уже разобранных правил.
- Задание должно содержать условие, сигнатуру, примеры, ограничения и критерии проверки.
