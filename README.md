## Запуск

Целевая и минимальная версия курса — Python 3.14.

В лекциях возможности, появившиеся сравнительно недавно, отмечаются отдельными врезками вида «Появилось в Python 3.10» или «Новое в Python 3.14». Это помогает отличать базовые свойства языка от свежих дополнений и понимать, почему в старом коде встречаются другие решения.

### 1. Подготовьте Python и виртуальное окружение

Установите Python **3.14** со [страницы загрузок Python](https://www.python.org/downloads/). Скачайте или клонируйте репозиторий курса и откройте терминал в его корневой папке — там, где лежат `README.md` и `requirements.txt`. Все команды ниже выполняются из этой папки.

**macOS / Linux, терминал bash или zsh:**

```bash
python3.14 --version
python3.14 -m venv .venv
source .venv/bin/activate
```

**Windows, PowerShell:**

```powershell
py -3.14 --version
py -3.14 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Если PowerShell запрещает запуск `Activate.ps1`, откройте обычную командную строку **cmd** в папке курса и активируйте уже созданное окружение:

```bat
.venv\Scripts\activate.bat
```

Папка `.venv` хранит отдельный Python и пакеты для курса. После активации команда `python` должна указывать на это окружение; обычно в начале строки терминала появляется `(.venv)`. Подробнее — в [документации `venv`](https://docs.python.org/3.14/library/venv.html).

### 2. Установите зависимости и ipykernel

В активированном окружении выполните одинаковые для всех систем команды:

```bash
python --version
python -m pip install --upgrade pip
python -m pip install -r requirements.txt ipykernel
```

Первая команда должна показать `Python 3.14.x`. Зависимости курса включают JupyterLab и библиотеки для примеров. `ipykernel` позволяет запускать Python-код из ячеек ноутбука; устанавливаем его явно в то же окружение. Для установки пакетов нужен интернет.

### 3. Зарегистрируйте ядро курса

**Ядро (kernel)** — процесс Python, который выполняет ячейки и хранит созданные переменные. JupyterLab или VS Code показывают ноутбук, а выбранное ядро определяет, какая версия Python и какие пакеты доступны коду.

```bash
python -m ipykernel install --user --name hse-python-314 --display-name "Python 3.14 (HSE)"
```

Команду нужно выполнить из активированного `.venv`. Она добавит ядро **Python 3.14 (HSE)** в список доступных; права администратора не нужны. Регистрацию достаточно сделать один раз. После пересоздания окружения повторите шаги 2 и 3. При переносе папки курса создайте новое окружение по шагам 1–3: `.venv` привязано к прежнему пути. См. [инструкцию IPython по установке ядер](https://ipython.readthedocs.io/en/stable/install/kernel_install.html).

### 4. Откройте ноутбук

Выберите удобный вариант.

**В браузере через JupyterLab:**

```bash
python -m jupyterlab
```

Откроется вкладка браузера с локальным JupyterLab. Если этого не произошло, перейдите по адресу, который напечатан в терминале. Оставьте терминал открытым на время работы.

В списке файлов откройте `lesson01/lecture.ipynb`. Нажмите на название ядра в правом верхнем углу ноутбука и выберите **Python 3.14 (HSE)**. После занятия остановите сервер сочетанием **Ctrl+C** в терминале и подтвердите остановку, если появится запрос. Подробнее — в [документации по запуску JupyterLab](https://jupyterlab.readthedocs.io/en/stable/getting_started/starting.html).

**В VS Code:**

1. Установите расширения **Python** и **Jupyter** от Microsoft.
2. Откройте папку курса через **File → Open Folder**.
3. В палитре команд (**Ctrl+Shift+P**, на macOS **Cmd+Shift+P**) выполните **Python: Select Interpreter** и выберите Python из `.venv` этой папки.
4. Откройте `lesson01/lecture.ipynb` и нажмите **Select Kernel** справа сверху. Выберите **Python 3.14 (HSE)**. Если его нет среди последних использованных ядер, откройте **Select Another Kernel → Jupyter Kernels**. Можно также выбрать **Python Environments** и указать `.venv` курса.

Для локальной работы в VS Code отдельно запускать JupyterLab не требуется. Выбор интерпретатора для `.py`-файлов и выбор ядра ноутбука — отдельные настройки; проверьте обе. См. [документацию VS Code по ядрам](https://code.visualstudio.com/docs/datascience/jupyter-kernel-management).

#### Перезапуск в VS Code

**Чтобы начать выполнение ноутбука с чистого состояния:**

1. Откройте нужный `.ipynb` и на верхней панели ноутбука нажмите кнопку перезапуска ядра — круговую стрелку **Restart / Restart Kernel**.
2. Подтвердите перезапуск, если появится запрос, и дождитесь готовности ядра.
3. Нажмите **Run All**, чтобы выполнить лекцию сверху вниз. В семинаре запускайте нужные ячейки по порядку: незавершённые задания могут намеренно выдавать ошибки.

Перезапуск сбрасывает переменные и определения функций в памяти. Код в ячейках и установленные пакеты сохраняются. Старые выводы могут оставаться видимыми; кнопка **Clear All Outputs** очищает их, но сама по себе не сбрасывает переменные. Если ячейка зависла, сначала попробуйте **Interrupt** — остановку выполнения; если она не помогла, перезапустите ядро. Кнопки находятся на [панели управления ноутбуком](https://code.visualstudio.com/docs/datascience/jupyter-notebooks#_clear-output-or-restartinterrupt-the-kernel).

**Если после установки расширений или регистрации ядра VS Code не обновил список окружений:** откройте палитру команд (**Ctrl+Shift+P**, на macOS **Cmd+Shift+P**), выполните **Developer: Reload Window** и снова проверьте **Select Kernel**. Эта команда перезагружает окно редактора и расширения. Для проверки вычислений с чистого состояния используйте перезапуск ядра по инструкции выше.

### 5. Проверьте окружение в самом ноутбуке

Создайте кодовую ячейку и выполните её сочетанием **Shift+Enter**:

```python
import sys

print(sys.version)
print(sys.executable)
print(2 + 2)
```

Ожидаются версия `3.14.x`, путь к Python внутри `.venv` курса и число `4`. Например, на macOS / Linux путь может заканчиваться на `.venv/bin/python` или `.venv/bin/python3.14`, на Windows — на `.venv\Scripts\python.exe`.

Запускайте ячейки лекции сверху вниз. Они используют общие переменные, которые сохраняются до перезапуска ядра. Чтобы проверить лекцию с чистого состояния, перезапустите ядро и выполните все ячейки (**Restart Kernel**, затем **Run All**). В семинарах ячейки с заданиями могут намеренно завершаться ошибкой, пока вы не допишете решение.

При следующем запуске достаточно открыть терминал в папке курса, активировать `.venv` командой из шага 1 и запустить `python -m jupyterlab` либо открыть ноутбук в VS Code. Повторно создавать окружение и регистрировать ядро не нужно. После обновления `requirements.txt` повторите установку зависимостей из шага 2.

### Если что-то не запускается

| Что происходит | Что проверить |
| --- | --- |
| Команда `python3.14` или `py` не найдена | Установлен ли Python 3.14; после установки закройте и заново откройте терминал. На Windows проверьте доступность команды `py`. |
| `No module named ipykernel` или `No module named jupyterlab` | Активируйте `.venv` и повторите установку из шага 2. |
| Ядра курса нет в списке | Повторите шаг 3, проверьте список командой `python -m jupyter kernelspec list`, затем переоткройте ноутбук. |
| В ячейке `ModuleNotFoundError`, хотя пакет установлен | Сравните `sys.executable` в ноутбуке с путём к `.venv` курса. Выберите нужное ядро, установите зависимости в это окружение и перезапустите ядро. |
| Ноутбук использует старую версию Python | Проверьте `sys.version` в ячейке и выберите ядро курса. Активация окружения в терминале не переключает уже запущенное ядро. |
| Возникает `NameError` для переменной из предыдущей ячейки | Выполните предыдущие ячейки по порядку; после перезапуска ядра переменные нужно создать заново. |

### Особенности учебных примеров

Некоторые примеры занятия 12 выполняют HTTP-запросы и требуют подключения к интернету. Все остальные основные материалы должны работать локально.

Кодовые ячейки размечены тегами:

- `demo` — исполняемый пример;
- `exercise` — заготовка, которую должен дописать студент;
- `network` — пример требует интернета;
- `jupyter-only` — используется возможность Jupyter, например top-level `await`;
- `slow` и `blocking-demo` — намеренно медленный пример блокирующего кода.

## Правила оформления материалов

- Актуальные сроки сдачи и правила штрафов хранятся в отдельном файле [`DEADLINES.md`](DEADLINES.md), а не в ноутбуках.
- Перед публикацией у всех ячеек очищаются результаты и номера запусков.
- Намеренно ошибочные примеры должны быть явно помечены в тексте.
- В конце каждой лекции есть раздел «Неожиданно, но по правилам»: короткие примеры контринтуитивного поведения, которое следует из уже разобранных правил.
- Задание должно содержать условие, сигнатуру, примеры, ограничения и критерии проверки.
