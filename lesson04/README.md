## Результаты обучения

После занятия студент умеет:

- различать основные области применения Python и их типовую архитектуру;
- оценивать, подходит ли Python для конкретной задачи;
- формулировать проблему проекта через пользователя, вход, выход и критерий успеха;
- собирать команду из 2–4 человек, регистрировать тему и планировать контрольные точки;
- отделять предметное ядро от файлов, сети и CLI;
- создавать репозиторий, виртуальное окружение и устанавливаемый пакет;
- описывать проект через `pyproject.toml` и `src`-layout;
- запускать CLI через console entry point;
- выполнять `ruff` и smoke-тест одной воспроизводимой последовательностью;
- работать в отдельных ветках и осознанно разрешать merge conflict.

## Контрольная точка проекта

После занятия группа выбирает предметную область, формулирует задачу, регистрирует состав и создаёт репозиторий. Команда фиксирует пользователя, ожидаемый результат, границы первой версии, куратора и ближайший план. Использование конкретного фреймворка на этой стадии не требуется.

## Самостоятельная работа

Домашняя работа состоит из трёх Easy- и двух Medium-задач инженерного уровня. Часть заданий можно выполнять непосредственно в репозитории группового проекта.
