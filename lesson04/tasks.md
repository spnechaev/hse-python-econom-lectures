## Easy 1. Знак числа

Реализуйте функцию:

```python
def sign(number: int) -> int:
    ...
```

Верните `-1`, если число отрицательное, `0`, если оно равно нулю, и `1`, если оно положительное.

Примеры:

```python
sign(-15) == -1
sign(0) == 0
sign(23) == 1
sign(-1) == -1
sign(1) == 1
```

Ограничения:

- `-10**9 <= number <= 10**9`;
- используйте условия; внешние библиотеки не нужны.

Критерии проверки:

- возвращается одно из трёх целых чисел `-1`, `0`, `1`;
- ноль обработан отдельно;
- функция возвращает результат, а не печатает его.

## Easy 2. Делится без остатка

Реализуйте функцию:

```python
def is_divisible(number: int, divisor: int = 2) -> bool:
    ...
```

Верните `True`, если `number` делится на `divisor` без остатка, иначе `False`. Если второй аргумент не передан, функция проверяет делимость на `2`. Ноль делится без остатка на любое допустимое значение `divisor`.

Примеры:

```python
is_divisible(8) is True
is_divisible(7) is False
is_divisible(15, 5) is True
is_divisible(15, divisor=4) is False
is_divisible(-12, 3) is True
is_divisible(12, -3) is True
is_divisible(0, 7) is True
```

Ограничения:

- `-10**9 <= number <= 10**9`;
- `-10**9 <= divisor <= 10**9`, `divisor != 0`.

Критерии проверки:

- результат имеет тип `bool`;
- работают вызовы с одним аргументом, с двумя позиционными и с именованным аргументом `divisor`;
- отрицательные числа и отрицательные делители обрабатываются по тому же правилу.

## Easy 3. Факториал

Реализуйте рекурсивную функцию:

```python
def factorial(n: int) -> int:
    ...
```

Факториал положительного целого числа — произведение всех целых чисел от `1` до него включительно. Например, факториал `4` равен `1 * 2 * 3 * 4 = 24`. Факториал нуля по определению равен `1`.

Примеры:

```python
factorial(0) == 1
factorial(1) == 1
factorial(4) == 24
factorial(5) == 120
factorial(7) == 5040
```

Ограничения:

- `0 <= n <= 100`;
- используйте рекурсию;
- не используйте циклы, comprehensions и готовые функции вычисления произведения или факториала.

Критерии проверки:

- корректно обработаны `n == 0` и `n == 1`;
- функция возвращает целое число;
- все допустимые вызовы завершаются;
- результат одного вызова не зависит от предыдущих вызовов.

В объяснении проследите вычисление `factorial(3)` и укажите порядок возвращения результатов.

## Medium 1. Подсчитать имена

Реализуйте две функции:

```python
def normalize_name(name: str) -> str:
    ...


def count_names(names: list[str]) -> dict[str, int]:
    ...
```

`normalize_name` приводит запись имени к единому виду:

- убирает пробельные символы по краям;
- заменяет каждую последовательность пробельных символов внутри строки одним обычным пробелом;
- переводит буквы в нижний регистр с помощью `str.lower()`.

Пробельными считаются символы, которые Python обрабатывает как разделители в `str.split()` без аргументов, в том числе пробел, табуляция и перевод строки. Остальные символы сохраняются. Пустая строка и строка из одних пробельных символов превращаются в `""`.

`count_names` вызывает `normalize_name` для каждой записи и возвращает словарь: нормализованное имя → число его вхождений. Пустые имена не учитываются. Разные исходные записи, совпавшие после нормализации, считаются одним именем. Порядок ключей в ответе не важен.

Примеры:

```python
normalize_name("  Анна   Мария ") == "анна мария"
normalize_name("ИВАН\tПЕТРОВ") == "иван петров"
normalize_name(" \t\n ") == ""

count_names([" Анна ", "ИВАН", "анна", "", "   "]) == {"анна": 2, "иван": 1}
count_names(["Анна  Мария", " анна\tмария "]) == {"анна мария": 2}
count_names(["Ли", "Ли", "ли"]) == {"ли": 3}
count_names(["", " \t "]) == {}
count_names([]) == {}
```

Ограничения:

- `0 <= len(names) <= 10_000`;
- длина каждой строки — не больше 100 символов;
- `count_names` должна использовать написанную вами `normalize_name`;
- не используйте `collections.Counter` и другие готовые функции подсчёта частот;
- требуемое время — `O(L + n)` в среднем, где `n` — число записей, а `L` — суммарная длина исходных строк.

Критерии проверки:

- каждое непустое нормализованное имя учтено ровно один раз за каждое вхождение;
- значения словаря — положительные целые числа;
- обе функции можно вызвать и проверить отдельно;
- исходный список не изменяется;
- функция не накапливает результаты между вызовами.

Оцените память с учётом длины имён в словаре результата.

## Medium 2. Сумма с учётом глубины

Реализуйте функцию:

```python
def weighted_sum(items: list) -> int:
    ...
```

Каждый элемент списка — целое число или вложенный список с такими же правилами. Верните сумму всех чисел, умножив каждое на его глубину: числа во внешнем списке имеют глубину `1`, в списке внутри него — `2` и так далее.

Например, для `[1, [2, [3]], 4]` ответ равен `1 * 1 + 2 * 2 + 3 * 3 + 4 * 1 = 18`. Пустые списки не добавляют ничего к сумме. Отрицательные числа сохраняют знак.

Примеры:

```python
weighted_sum([1, [2, [3]], 4]) == 18
weighted_sum([1, 2, 3]) == 6
weighted_sum([[1], [1]]) == 4
weighted_sum([[[5]]]) == 15
weighted_sum([-1, [2, [-3]]]) == -6
weighted_sum([[], [[]]]) == 0
weighted_sum([]) == 0
```

Ограничения:

- списки конечны, циклических ссылок нет; других типов, кроме `int` и `list`, во входе нет;
- суммарное число элементов во всех списках — не больше `10_000`; числа и вложенные списки считаются отдельными элементами;
- глубина — не больше 50 уровней списков, включая внешний;
- каждое число — от `-1000` до `1000`;
- используйте рекурсию для обработки вложенности; циклы по элементам текущего списка разрешены;
- требуемое время — `O(n)`, где `n` — единица плюс суммарное число элементов во всех списках;
- вспомогательная память — `O(h)`, где `h` — максимальная глубина вложенности.

Критерии проверки:

- каждое число учитывается с глубиной именно своего вхождения;
- одинаковые числа на разных уровнях могут давать разный вклад;
- пустые списки и отрицательные числа обработаны корректно;
- ни внешний список, ни вложенные не изменяются;
- последовательные вызовы работают независимо.

Объясните, почему ширина списка и глубина вложенности по-разному влияют на время и память.

## Hard 1. Распаковать строку

Необязательная задача на идею.

Реализуйте функцию:

```python
def decode(text: str) -> str:
    ...
```

В строке встречаются строчные латинские буквы и записи вида `k[фрагмент]`. Такая запись означает: декодировать фрагмент внутри скобок и повторить результат `k` раз. Фрагмент может содержать буквы и другие такие записи. Соседние фрагменты соединяются без разделителей.

Например, `3[ab]` превращается в `"ababab"`, а `2[a3[b]]` — в `"abbbabbb"`. Число повторений может состоять из нескольких цифр. Пустой фрагмент разрешён: `2[]` даёт пустую строку.

Примеры:

```python
decode("3[ab]2[c]") == "abababcc"
decode("2[a3[b]]c") == "abbbabbbc"
decode("x2[yz]q") == "xyzyzq"
decode("10[x]") == "xxxxxxxxxx"
decode("2[3[a]b]") == "aaabaaab"
decode("2[]a") == "a"
decode("abc") == "abc"
decode("") == ""
```

Ограничения:

- `0 <= len(text) <= 1000`;
- запись всегда корректна: скобки согласованы, непосредственно перед каждой `[` стоит число повторений;
- числа повторений — от `1` до `100`, без ведущих нулей; вне этого положения цифр нет;
- других символов, кроме `a`–`z`, цифр и квадратных скобок, нет;
- одновременно вложено не больше 50 пар скобок;
- длина декодированного результата — не больше `100_000` символов;
- используйте рекурсию для разбора вложенных фрагментов; циклы разрешены.

Критерии проверки:

- корректно обрабатываются вложенные и соседние записи;
- многозначное число повторений читается целиком;
- буквы до и после повторяемого фрагмента сохраняются;
- пустая строка и пустые фрагменты обрабатываются корректно;
- объяснено, почему каждый вызов обрабатывает нужный фрагмент и где заканчивается его работа.

Оцените время и память через длину исходной строки, длину результата и глубину вложенности. Учитывайте стоимость создания и копирования строк.
