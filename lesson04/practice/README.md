# Собственный модуль: задание 6

Условие находится в [семинаре 4](../seminar.ipynb).

1. Заполните `library_tools.py` своими функциями `return_day` и `missing_items` из заданий 3 и 4. Добавьте нужные им импорты.
2. В `show_report.py` добавьте две формы импорта из условия и заполните `main()`.
3. Запустите программу и проверки из корня курса:

```bash
python lesson04/practice/show_report.py
python lesson04/practice/check_practice.py
```

Если терминал открыт в `lesson04`, используйте `python practice/show_report.py` и `python practice/check_practice.py`.

До написания функций `NotImplementedError` ожидаем: в файлах оставлены заготовки. Проверки контролируют результаты, отсутствие печати при импорте и вывод программы при прямом запуске. Выбор двух форм импорта проверьте по своему коду: один результат вычисляется через `library_tools.return_day`, другой — через отдельно импортированную `missing_items`.

Нужен только Python 3.14. Каждый запуск команды создаёт новый интерпретатор, поэтому изменения файлов видны без перезапуска ядра ноутбука.
