# Собственный модуль: задание 6

Условие находится в [семинаре 4](../seminar.ipynb). Эта папка — вариант для тех, кто работает
локально и предпочитает обычные файлы и терминал. В самом семинаре то же задание выполняется
прямо из ноутбука: файлы создаются ячейками `%%writefile`, а проверка запускает их отдельным
интерпретатором. Делать нужно что-то одно.

1. Заполните `report_tools.py` своими функциями `report_due` и `missing_items` из заданий 2 и 4. Добавьте нужные им импорты.
2. В `show_report.py` добавьте две формы импорта из условия и заполните `main()`.
3. Запустите программу и проверки из корня курса:

```bash
python lesson04/practice/show_report.py
python lesson04/practice/check_practice.py
```

Если терминал открыт в `lesson04`, используйте `python practice/show_report.py` и `python practice/check_practice.py`.

До написания функций `NotImplementedError` ожидаем: в файлах оставлены заготовки. Проверки контролируют результаты, отсутствие печати при импорте и вывод программы при прямом запуске. Выбор двух форм импорта проверьте по своему коду: один результат вычисляется через `report_tools.report_due`, другой — через отдельно импортированную `missing_items`.

Нужен Python 3.10 или новее. Каждый запуск команды создаёт новый интерпретатор, поэтому изменения файлов видны без перезапуска ядра ноутбука.
