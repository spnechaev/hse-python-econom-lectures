# Занятие 02. Задачи для самостоятельного решения

Каждое решение оформляется как функция с указанной сигнатурой. При работе с текстом используйте кодировку UTF-8. Функции не должны печатать диагностические сообщения.

## Easy 1. Код для URL

Реализуйте функцию:

```python
def make_slug(title: str) -> str:
    ...
```

Удалите пробелы по краям, переведите слова в нижний регистр и соедините их дефисом. Между словами может быть несколько пробелов.

Примеры:

```python
make_slug("  Household   Income  ") == "household-income"
make_slug("Python Basics") == "python-basics"
make_slug("   ") == ""
```

Ограничения:

- длина строки не превосходит `10_000` символов;
- строка содержит латинские буквы, цифры и пробелы.

Критерии проверки:

- повторяющиеся пробелы не создают пустых частей;
- буквы переведены в нижний регистр;
- в результате нет дефисов по краям.

## Easy 2. Числа из файла

Реализуйте функцию:

```python
def read_integers(path: str) -> list[int]:
    ...
```

Файл содержит по одному целому числу в строке. Пустые строки нужно пропустить. Верните числа в исходном порядке.

Пример файла:

```text
10

-3
25
```

Результат:

```python
[10, -3, 25]
```

Ограничения:

- кодировка файла UTF-8;
- пробелы по краям строки незначимы;
- при некорректном числе должен возникнуть `ValueError`;
- при отсутствии файла должен сохраниться `FileNotFoundError`.

Критерии проверки:

- файл открывается через `with` или `Path.read_text`;
- пустые строки пропускаются;
- файл не остаётся открытым после завершения функции.

## Easy 3. Вид команды

Реализуйте функцию:

```python
def command_kind(command: str) -> str:
    ...
```

Разберите `command.split()` с помощью `match/case`:

- `show NAME` → `show`;
- `save NAME` → `save`;
- `quit` или `exit` → `stop`;
- любой другой вариант → `unknown`.

Примеры:

```python
command_kind("show report") == "show"
command_kind("save result") == "save"
command_kind("exit") == "stop"
command_kind("show too many words") == "unknown"
```

Ограничения:

- имя состоит из одного непустого слова;
- использовать цепочку сравнений всей строки через `if/elif` нельзя.

Критерии проверки:

- проверяется структура списка слов;
- `quit` и `exit` объединены одним шаблоном `|`;
- `case _` обрабатывает остальные варианты.

## Medium 1. Прямоугольная CSV-таблица

Реализуйте функцию:

```python
def read_rectangular_csv(path: str) -> list[list[str]]:
    ...
```

Прочитайте CSV через стандартный модуль `csv`. Пустые строки пропустите, пробелы по краям каждой ячейки удалите. Все непустые строки должны содержать одинаковое количество столбцов. Если встретилась строка другой длины, выбросьте `ValueError` с номером строки.

Пример:

```text
name, value
GDP, 105.2
CPI, 109.4
```

Результат:

```python
[["name", "value"], ["GDP", "105.2"], ["CPI", "109.4"]]
```

Ограничения:

- кодировка UTF-8;
- в файле может быть до `100_000` строк;
- запятые внутри кавычек должны обрабатываться корректно, поэтому `line.split(",")` использовать нельзя.

Критерии проверки:

- используется `csv.reader`;
- корректно обрабатываются пустой файл и пустые строки;
- номер ошибочной строки присутствует в сообщении `ValueError`;
- результат не содержит незначимых пробелов по краям ячеек.

## Medium 2. CSV в JSON

Реализуйте функцию:

```python
def transactions_to_json(source_path: str, target_path: str) -> int:
    ...
```

Исходный CSV содержит заголовок `account,amount`. Каждую последующую строку преобразуйте в пару `[account, amount]`, где `amount` имеет тип `int`. Запишите список пар в JSON и верните количество записанных операций.

Пример CSV:

```text
account,amount
cash,100
deposit,-25
```

Содержимое JSON после преобразования:

```json
[["cash", 100], ["deposit", -25]]
```

Ограничения:

- оба файла используют UTF-8;
- заголовок должен в точности совпадать с ожидаемым, иначе выбрасывается `ValueError`;
- каждая строка должна содержать два поля и корректное целое число;
- JSON записывается с `ensure_ascii=False` и отступом `2`.

Критерии проверки:

- используются модули `csv` и `json`;
- файлы закрываются при успешном завершении и при ошибке;
- некорректные данные не маскируются общим `except Exception`;
- функция возвращает число записанных операций.
