## Easy 1. Код для URL

Реализуйте функцию:

```python
def make_slug(title: str) -> str:
    ...
```

Удалите пробелы по краям, переведите слова в нижний регистр и соедините их дефисом. Между словами может быть несколько пробелов.

Примеры:

```python
make_slug("  Household   Income  ") == "household-income"
make_slug("Python Basics") == "python-basics"
make_slug("   ") == ""
```

Ограничения:

- длина строки не превосходит `10_000` символов;
- строка содержит латинские буквы, цифры и пробелы.

Критерии проверки:

- повторяющиеся пробелы не создают пустых частей;
- буквы переведены в нижний регистр;
- в результате нет дефисов по краям.

## Easy 2. Запись о товаре

Реализуйте функцию:

```python
def parse_item(text: str) -> tuple[str, int]:
    ...
```

Строка содержит название товара и его количество. Верните кортеж `(название, количество)`: название сохраняет регистр, количество имеет тип `int`. Между частями и по краям могут быть пробелы.

Примеры:

```python
parse_item("  notebook   12  ") == ("notebook", 12)
parse_item("Pen 0") == ("Pen", 0)
parse_item("tea 007") == ("tea", 7)
```

Ограничения:

- вход всегда содержит ровно две непустые части, разделённые пробелами;
- название состоит из латинских букв;
- количество записано цифрами и лежит в диапазоне от `0` до `1_000_000`;
- длина строки не превосходит `1_000` символов.

Критерии проверки:

- результат — кортеж из строки и целого числа;
- лишние пробелы не попадают в название;
- корректно обрабатываются ноль и ведущие нули.

## Easy 3. Общие товары

Реализуйте функцию:

```python
def common_products(first: list[str], second: list[str]) -> set[str]:
    ...
```

Два списка содержат названия товаров, заказанных двумя покупателями. Верните множество товаров, которые есть в обоих списках. Повторы не влияют на результат. Названия уже приведены к единому виду и не требуют обработки.

Примеры:

```python
common_products(["tea", "bread", "tea"], ["milk", "tea"]) == {"tea"}
common_products(["tea"], ["bread"]) == set()
common_products([], ["tea"]) == set()
```

Ограничения:

- в каждом списке не более `10_000` названий;
- каждое название — непустая строка длиной не более `100` символов.

Критерии проверки:

- результат имеет тип `set` и не содержит повторов;
- возвращаются только товары из обоих списков;
- пустые списки обрабатываются корректно;
- входные списки не изменяются.

## Medium 1. Записка из букв (Ransom Note)

Источник: [LeetCode 383. Ransom Note](https://leetcode.com/problems/ransom-note/description/).

Реализуйте функцию:

```python
def can_construct(ransom_note: str, magazine: str) -> bool:
    ...
```

Даны две строки: `ransom_note` — текст записки, `magazine` — буквы, доступные для её составления. Верните `True`, если из букв `magazine` можно составить `ransom_note`, и `False` в противном случае.

Каждое вхождение буквы в `magazine` можно использовать только один раз. Буквы разрешено переставлять; использовать все доступные буквы необязательно.

Примеры:

```python
can_construct("a", "b") == False
can_construct("aa", "ab") == False
can_construct("aa", "aab") == True
can_construct("abc", "cba") == True
can_construct("aaa", "aa") == False
```

Ограничения:

- длина каждой строки — от `1` до `100_000` символов;
- обе строки содержат только строчные латинские буквы.

Критерии проверки:

- учитывается число доступных вхождений каждой буквы;
- отсутствие нужной буквы или нехватка её вхождений приводит к `False`;
- порядок букв в `magazine` не влияет на результат;
- лишние буквы в `magazine` не мешают составить записку;
- результат имеет тип `bool`.

## Medium 2. Сводка по счетам

Реализуйте функцию:

```python
def account_summary(operations: list[tuple[str, int]]) -> dict[str, tuple[int, int]]:
    ...
```

Каждая операция — кортеж `(счёт, сумма)`. Положительная сумма обозначает поступление, отрицательная — списание, нулевая тоже считается отдельной операцией.

Верните словарь: ключ — название счёта, значение — кортеж `(сумма всех операций, число операций)` по этому счёту. Начальная сумма каждого счёта равна нулю. Счета с итоговой суммой 0 должны остаться в результате. Порядок ключей соответствует первому появлению счетов во входном списке.

Примеры:

```python
account_summary([("cash", 100), ("deposit", -25), ("cash", -40)]) == {
    "cash": (60, 2),
    "deposit": (-25, 1),
}
account_summary([("cash", 10), ("cash", -10), ("reserve", 0)]) == {
    "cash": (0, 2),
    "reserve": (0, 1),
}
account_summary([]) == {}
```

Ограничения:

- не более `100_000` операций;
- название счёта — непустая строка длиной не более `100` символов;
- сумма — целое число от `-1_000_000` до `1_000_000`;
- каждое вхождение операции учитывается, даже если такой же кортеж уже встречался.

Критерии проверки:

- для каждого счёта верны и сумма, и число операций;
- нулевые суммы и повторяющиеся операции не теряются;
- значения результата — кортежи из двух целых чисел;
- сохраняется порядок первого появления счетов;
- входной список не изменяется.
