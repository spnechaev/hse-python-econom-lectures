## Результаты обучения

После занятия студент умеет:

- обращаться к символам строки и элементам списка по индексам и срезам;
- форматировать строки и явно преобразовывать текстовый ввод;
- использовать строковые методы, методы списка и comprehensions;
- разбирать структурированные данные через `match/case`;
- строить пути через `pathlib.Path`;
- читать и записывать текстовые файлы с явной кодировкой;
- использовать контекстный менеджер `with`;
- читать и записывать CSV и JSON;
- читать traceback начиная с типа и причины ошибки;
- явно обрабатывать ожидаемые ошибки ввода и файловой системы.

## Самостоятельная работа

Основной набор состоит из трёх задач Easy и двух задач Medium. Отдельной Hard-задачи после второго занятия нет.
