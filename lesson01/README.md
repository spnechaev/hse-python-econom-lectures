## Результат занятия

Студент переводит небольшое словесное условие в функцию на Python, возвращает результат и проверяет обычный случай и границы. Предполагается опыт программирования на любом языке; знание Python и экономических дисциплин не требуется.

В лекции два связанных ряда примеров:

- длина имени в игре → условие → функция → проверки границ;
- прочитанные страницы → вычисления → накопитель в `for` → завершение процесса в `while`.

По ходу вводятся преобразование строки в число, f-строки, truthiness, короткое замыкание логических операций, `range`, `break`, `continue`, локальные имена и базовые аннотации типов. Отдельно разбирается простое сообщение об ошибке.

В разделе «Перед началом» — короткое знакомство с Zen of Python через `import this` и примеры лекции, затем основы PEP 8: отступы, имена, пробелы, пустые строки и длина строки. Две записи одной функции позволяют сравнить читаемость без изменения правила проверки.

## Что остаётся для самостоятельного чтения

В конце лекционного ноутбука размещены:

- полные правила оценивания, защиты, проекта и получения помощи;
- справка по именам, операциям, вариантам `range`, именованным аргументам и значениям по умолчанию;
- дополнительный пример с изменяемым значением по умолчанию. Он не нужен для семинара и домашней работы; к механизму общих ссылок возвращаемся на занятии 5.

Полные формулы и правила также находятся в [программе курса](../COURSE_PLAN.md), сроки — в [DEADLINES.md](../DEADLINES.md).

## Семинар

Основная работа — задания 1–5: преобразование текста в число, проверка длины надписи, сумма кратных, чтение книги за несколько дней и исправление `print` вместо `return`. Задание 6 о простых числах — дополнительное.

Кодовые ячейки содержат незавершённые заготовки: их проверки намеренно не проходят до решения задания. Работать нужно по одной задаче, дописывая функцию и запуская её проверки.

## Самостоятельная работа

Основной набор состоит из трёх задач Easy и двух задач Medium:

- ориентация изображения;
- количество делителей;
- сумма цифр;
- самая длинная серия одинаковых цифр;
- улитка на стене: подъём, откат и условие завершения.

Каждое решение оформляется как функция в `homework01.py`. Для задач достаточно основного материала лекции; необходимые правила приведены в условиях. Отдельной Hard-задачи после первого занятия нет.
