# Занятие 01. Задачи для самостоятельного решения

Каждое решение оформляется как функция с указанной сигнатурой. Функция возвращает результат и не использует `input` или `print`.

Сначала сформулируйте правило словами, затем напишите код и проверьте обычный случай и границы. Значения аргументов соответствуют ограничениям: отдельно проверять их корректность пока не требуется.

## Easy 1. Ориентация изображения

Реализуйте функцию:

```python
def image_orientation(width: int, height: int) -> str:
    ...
```

Ширина и высота изображения заданы в пикселях. Верните:

- `landscape`, если ширина больше высоты;
- `portrait`, если высота больше ширины;
- `square`, если размеры равны.

Примеры:

```python
image_orientation(1920, 1080) == "landscape"
image_orientation(600, 800) == "portrait"
image_orientation(500, 500) == "square"
```

Ограничения:

- `1 <= width, height <= 100_000`;
- возвращаемая строка должна точно совпадать с одной из трёх строк в условии.

Критерии проверки:

- корректно различаются все три случая;
- равные размеры не попадают в соседнюю ветвь;
- функция возвращает строку и ничего не печатает.

## Easy 2. Количество делителей


Верните количество положительных делителей числа `number`.

Примеры:

```python
count_divisors(1) == 1
count_divisors(6) == 4
count_divisors(12) == 6
```

Ограничения:

Критерии проверки:

- используется цикл и операция `%`;

## Easy 3. Сумма цифр

Реализуйте функцию:

```python
def digit_sum(number: int) -> int:
    ...
```

Верните сумму цифр десятичной записи неотрицательного целого числа. Например, для 507 сумма равна `5 + 0 + 7 = 12`.

Арифметическая подсказка: `number % 10` даёт последнюю цифру, а `number // 10` убирает её. Например, `507 % 10 == 7`, `507 // 10 == 50`. Повторяя эти операции, можно разобрать всё число.

Примеры:

```python
digit_sum(0) == 0
digit_sum(507) == 12
digit_sum(1000) == 1
digit_sum(99) == 18
```

Ограничения:

- `0 <= number <= 10**18`;
- используйте `while`, `//` и `%`, без преобразования числа в строку.

Критерии проверки:

- каждая цифра учитывается ровно один раз;
- нули внутри числа не мешают обработке следующих цифр;
- для числа 0 возвращается 0;
- цикл завершается.

## Medium 1. Самая длинная серия одинаковых цифр

Реализуйте функцию:

```python
def longest_digit_run(number: int) -> int:
    ...
```

Верните длину самой длинной непрерывной серии одинаковых цифр в десятичной записи числа. В числе `112223311` серии имеют длины 2, 3, 2 и 2, поэтому ответ равен 3. Отдельные серии одной и той же цифры не объединяются.

Для числа 0 ответ равен 1: его запись состоит из одной цифры.

Примеры:

```python
longest_digit_run(112223311) == 3
longest_digit_run(7777) == 4
longest_digit_run(1000) == 3
longest_digit_run(1112111) == 3
longest_digit_run(121212) == 1
longest_digit_run(0) == 1
```

Ограничения:

- `0 <= number <= 10**18`;
- используйте арифметический разбор цифр через `//` и `%`, без преобразования числа в строку;
- ведущих нулей в записи числа нет.

Критерии проверки:

- длина текущей серии и лучший найденный результат учитываются отдельно;
- при смене цифры начинается новая серия;
- самая длинная серия находится и в начале, и в середине, и в конце записи;
- корректно обрабатываются число из одной цифры и число 0.

Подсказка: при разборе справа налево порядок серий меняется, но длина каждой серии остаётся той же.

## Medium 2. Улитка на стене

Реализуйте функцию:

```python
def days_to_top(height: int, climb: int, slide: int) -> int:
    ...
```

Улитка начинает у подножия стены на высоте 0. За день она поднимается на `climb`. Если достигла высоты `height` или выше, подъём закончен. Иначе за ночь она сползает на `slide`, но не ниже земли, и на следующий день повторяет попытку.

Верните номер дня, когда улитка впервые достигнет верха. Если это невозможно, верните `-1`.

Например, при `height=10`, `climb=4`, `slide=1` к концу дневных подъёмов улитка оказывается на высотах 4, 7 и 10. Ответ — 3: после достижения верха ночного отката уже нет.

Примеры:

```python
days_to_top(10, 4, 1) == 3
days_to_top(10, 3, 1) == 5
days_to_top(5, 5, 7) == 1
days_to_top(10, 2, 2) == -1
days_to_top(10, 2, 3) == -1
days_to_top(7, 3, 0) == 3
```

Ограничения:

- `1 <= height, climb <= 1_000_000`;
- `0 <= slide <= 1_000_000`;
- используйте цикл для моделирования движения; формула числа дней не требуется;
- для возможного подъёма в этих границах потребуется не более `1_000_000` дней.

Критерии проверки:

- сначала учитывается дневной подъём, затем проверяется достижение верха и только потом ночной откат;
- случай достижения верха за один день работает даже при `slide >= climb`;
- невозможный случай обнаруживается без бесконечного цикла;
- равенство достигнутой высоты и `height` завершает подъём;
- нет ошибки на один день.
