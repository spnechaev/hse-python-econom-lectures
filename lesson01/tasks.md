# Занятие 01. Задачи для самостоятельного решения

Каждое решение оформляется как функция с указанной сигнатурой. Функция возвращает результат и не использует `input` или `print`.

## Easy 1. Финансовый результат

Реализуйте функцию:

```python
def financial_result(revenue: int, expenses: int) -> str:
    ...
```

Верните `profit`, если выручка больше расходов, `loss`, если расходы больше выручки, и `break-even`, если значения равны.

Примеры:

```python
financial_result(500, 450) == "profit"
financial_result(400, 500) == "loss"
financial_result(100, 100) == "break-even"
```

Ограничения:

- `0 <= revenue, expenses <= 10**12`;
- функция ничего не печатает.

Критерии проверки:

- три случая разделены корректно;
- равенство не попадает в соседнюю ветвь;
- возвращается строка с точным написанием из условия.

## Easy 2. Количество делителей

Реализуйте функцию:

```python
def count_divisors(number: int) -> int:
    ...
```

Верните количество положительных делителей числа `number`.

Примеры:

```python
count_divisors(1) == 1
count_divisors(6) == 4
count_divisors(12) == 6
```

Ограничения:

- `1 <= number <= 100_000`;
- достаточно проверить все числа от `1` до `number` включительно;
- оптимизация до квадратного корня пока не требуется.

Критерии проверки:

- используется цикл и операция `%`;
- само число и единица учитываются;
- результат возвращается, а не печатается.

## Easy 3. Сколько периодов до цели

Реализуйте функцию:

```python
def periods_to_target(capital: float, target: float, rate: float) -> int:
    ...
```

В конце каждого периода капитал увеличивается на долю `rate`. Верните минимальное число полных начислений, после которых капитал станет не меньше `target`.

Примеры:

```python
periods_to_target(100.0, 100.0, 0.10) == 0
periods_to_target(100.0, 121.0, 0.10) == 2
periods_to_target(100.0, 130.0, 0.10) == 3
```

Ограничения:

- `capital > 0`;
- `target >= capital`;
- `rate > 0`;
- использовать логарифмы не требуется.

Критерии проверки:

- применяется цикл `while`;
- случай уже достигнутой цели возвращает ноль;
- число периодов не завышено на единицу.

## Medium 1. Прогрессивный налог

Реализуйте функцию:

```python
def progressive_tax(income: int) -> float:
    ...
```

Налог рассчитывается по частям:

- первые `1_000_000` облагаются по ставке 10%;
- часть от `1_000_000` до `3_000_000` — по ставке 15%;
- часть сверх `3_000_000` — по ставке 20%.

Примеры:

```python
progressive_tax(0) == 0.0
progressive_tax(1_000_000) == 100_000.0
progressive_tax(4_000_000) == 600_000.0
```

Ограничения:

- `0 <= income <= 10**12`;
- ставка применяется только к соответствующей части дохода;
- округлять результат не требуется.

Критерии проверки:

- корректная работа на обеих границах;
- части дохода не облагаются повторно;
- функция возвращает числовой результат.

## Medium 2. Погашение долга

Реализуйте функцию:

```python
def months_to_repay(debt: float, payment: float, monthly_rate: float) -> int:
    ...
```

В начале каждого месяца на остаток долга начисляется доля `monthly_rate`, затем вносится платёж `payment`. Верните число месяцев до полного погашения. Если первый платёж не превышает начисленные за первый месяц проценты, долг не уменьшается — верните `-1`.

Примеры:

```python
months_to_repay(100.0, 100.0, 0.0) == 1
months_to_repay(100.0, 60.0, 0.0) == 2
months_to_repay(1000.0, 10.0, 0.02) == -1
```

Ограничения:

- `debt > 0`, `payment > 0`, `monthly_rate >= 0`;
- платёж в последний месяц может быть больше остатка;
- для корректных тестов число месяцев не превосходит `1_000_000`.

Критерии проверки:

- порядок «проценты, затем платёж» соблюдён;
- невозможный случай обнаруживается до цикла;
- цикл завершается при остатке `<= 0`;
- нет ошибки на один месяц.
