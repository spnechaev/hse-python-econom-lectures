## Результаты обучения

После занятия студент умеет:

- объяснить разницу между именем, объектом, значением и типом;
- отличить равенство объектов от их идентичности;
- предсказать последствия изменения объекта через несколько ссылок;
- выбрать подходящий встроенный контейнер;
- безопасно копировать плоские и вложенные структуры;
- использовать `Decimal` для точных денежных вычислений;
- распознавать типичные ошибки, связанные с `bool`, `None`, изменяемостью и хешируемостью.

## Самостоятельная работа

Основной набор состоит из трёх задач Easy и двух задач Medium. Отдельной Hard-задачи после пятого занятия нет.
