# Занятие 05. Задачи для самостоятельного решения

Все функции должны возвращать результат, а не печатать его. Не изменяйте переданные коллекции, если условие прямо не разрешает обратное. Денежные величины нельзя считать с помощью `float`.

## Easy 1. Чистые цены

Реализуйте функцию:

```python
def clean_prices(values: list[int | float | None]) -> list[float]:
    ...
```

Функция должна удалить значения `None`, преобразовать числа в `float` и сохранить исходный порядок. Значения типа `bool` необходимо отвергать исключением `TypeError`, несмотря на то что `bool` является подклассом `int`.

Примеры:

```python
clean_prices([10, None, 12.5, 8]) == [10.0, 12.5, 8.0]
clean_prices([]) == []
```

Ограничения:

- длина списка не превосходит `10_000`;
- входной список изменять нельзя;
- при первом значении `bool` нужно выбросить `TypeError`.

Критерии проверки:

- корректная фильтрация `None`;
- явное различение `bool` и чисел;
- сохранение порядка и неизменность аргумента.

## Easy 2. Уникальные категории

Реализуйте функцию:

```python
def unique_categories(categories: list[str]) -> list[str]:
    ...
```

Нужно удалить повторения без изменения порядка первых появлений. Регистр имеет значение, пробелы не удаляются.

Пример:

```python
unique_categories(["food", "taxi", "food", "Food", "taxi"])
# ["food", "taxi", "Food"]
```

Ограничения:

- до `100_000` элементов;
- каждый элемент является строкой;
- нельзя сортировать входные данные.

Критерии проверки:

- правильный порядок;
- отсутствие повторений;
- решение не должно выполнять полный линейный поиск по уже построенному результату для каждого элемента.

## Easy 3. Точная сумма

Реализуйте функцию:

```python
from decimal import Decimal

def exact_total(amounts: list[str]) -> Decimal:
    ...
```

Каждая строка содержит корректную десятичную денежную величину. Верните их точную сумму.

Примеры:

```python
exact_total(["0.10", "0.20"]) == Decimal("0.30")
exact_total([]) == Decimal("0")
exact_total(["10.50", "-2.25", "1.75"]) == Decimal("10.00")
```

Ограничения:

- до `100_000` значений;
- использовать `float` на любом этапе вычисления нельзя;
- форматировать или округлять результат не требуется.

Критерии проверки:

- результат имеет тип `Decimal`;
- сумма вычисляется без двоичной ошибки представления;
- пустой список обрабатывается корректно.

## Medium 1. Слияние остатков

Реализуйте функцию:

```python
from decimal import Decimal

def merge_balances(
    current: dict[str, Decimal],
    changes: dict[str, Decimal],
) -> dict[str, Decimal]:
    ...
```

Для каждого счёта из `changes` прибавьте изменение к текущему остатку. Если счёта ещё нет, его исходный остаток равен нулю. Счета, отсутствующие в `changes`, должны сохраниться. Словари-аргументы изменять нельзя.

Пример:

```python
current = {"cash": Decimal("100.00"), "deposit": Decimal("500.00")}
changes = {"cash": Decimal("-15.50"), "broker": Decimal("25.00")}

merge_balances(current, changes) == {
    "cash": Decimal("84.50"),
    "deposit": Decimal("500.00"),
    "broker": Decimal("25.00"),
}
```

Ограничения:

- суммарно не более `200_000` ключей;
- все значения уже имеют тип `Decimal`;
- порядок ключей результата не проверяется.

Критерии проверки:

- корректная обработка общих и новых счетов;
- исходные словари остаются неизменными;
- в результате нет общих изменяемых значений с аргументами.

## Medium 2. Независимый сценарий бюджета

Реализуйте функцию:

```python
from decimal import Decimal

Budget = dict[str, list[Decimal]]

def with_scenario(
    budget: Budget,
    category: str,
    month: int,
    value: Decimal,
) -> Budget:
    ...
```

Функция должна вернуть новый бюджет, в котором значение выбранной категории за указанный месяц заменено на `value`. Исходный бюджет и все вложенные в него списки должны остаться неизменными.

Пример:

```python
source = {
    "revenue": [Decimal("100"), Decimal("110")],
    "costs": [Decimal("70"), Decimal("75")],
}

scenario = with_scenario(source, "costs", 1, Decimal("90"))

scenario["costs"] == [Decimal("70"), Decimal("90")]
source["costs"] == [Decimal("70"), Decimal("75")]
scenario["revenue"] == source["revenue"]
scenario["revenue"] is not source["revenue"]
```

Если категории нет, выбросьте `KeyError`. Если индекс месяца выходит за границы списка, выбросьте `IndexError`.

Ограничения:

- до `1_000` категорий;
- в каждой категории до `1_000` месяцев;
- использовать `copy.deepcopy` нельзя: требуемое копирование нужно реализовать осознанно.

Критерии проверки:

- корректное изменение выбранного значения;
- полная независимость всех вложенных списков результата;
- исходная структура не изменяется;
- предусмотренные исключения сохраняют стандартные типы.
