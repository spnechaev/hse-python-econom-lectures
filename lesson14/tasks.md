# Занятие 14. Домашней работы нет

После последней лекции отдельные задачи Easy, Medium и Hard не выдаются.

Перед защитой команда проверяет:

- основной пользовательский сценарий запускается по инструкции из чистого окружения;
- автоматические тесты проходят;
- секреты не находятся в репозитории, notebook, image или логах;
- каждый участник понимает предметную задачу, архитектуру и ключевые решения;
- демонстрация укладывается в установленный регламент;
- известные ограничения сформулированы честно.

Изменения после защиты выполняются только по явной договорённости с преподавателем.
