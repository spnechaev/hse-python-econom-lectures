## Результаты обучения

После занятия студент умеет:

- проектировать небольшой REST API вокруг предметного ядра;
- разделять path/query-параметры, тело запроса и модель ответа;
- применять Pydantic для проверки входа и фильтрации ответа;
- возвращать подходящие HTTP-статусы и предметные ошибки;
- передавать ресурсы через dependency injection;
- управлять общими ресурсами приложения через `lifespan`;
- тестировать API через `TestClient` и подмену зависимостей;
- объяснять разницу между image и container;
- читать и писать минимальный Dockerfile и Compose-конфигурацию;
- передавать конфигурацию через окружение, не встраивая секреты в image;
- определять readiness/liveness через простой healthcheck;
- собирать минимальный CI-конвейер проверки;
- отличать запуск контейнера от полноценного production-деплоя.

## Темп занятия

Лекция рассчитана примерно на 90 минут неспешного рассказа: около 30 минут на REST, FastAPI и Pydantic, 15 минут на зависимости, lifespan и тестирование, 25 минут на image/container, Dockerfile и Compose, 10 минут на конфигурацию, healthcheck и CI, 10 минут на границы деплоя, контринтуитивные примеры и вопросы.

## Формат семинара

Семинар посвящён защите групповых проектов. Команда показывает работающий пользовательский сценарий, объясняет архитектуру и решения, отвечает на вопросы и получает итоговую обратную связь. FastAPI и Docker не обязательны: оценивается соответствие выбранных инструментов задаче.

## Самостоятельная работа

После последней лекции новой домашней работы нет. Незавершённые исправления проекта выполняются только по результатам защиты и по отдельному согласованию с преподавателем.
