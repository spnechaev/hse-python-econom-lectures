# Занятие 09. Задачи для самостоятельного решения

Каждое решение оформляется как функция с указанной сигнатурой. Функция возвращает результат и не использует `input` или `print`.

## Easy 1. Отмена последних изменений

Команды представлены парами `(action, value)`. `("add", value)` добавляет значение в историю, `("undo", None)` отменяет последнее добавление. Если отменять нечего, команда ничего не меняет.

```python
def apply_history(commands: list[tuple[str, str | None]]) -> list[str]:
    ...
```

Пример:

```python
commands = [
    ("add", "income"),
    ("add", "tax"),
    ("undo", None),
    ("add", "rent"),
]
assert apply_history(commands) == ["income", "rent"]
```

Ограничения:

- `0 <= len(commands) <= 200_000`;
- `action` равен `add` или `undo`;
- для `add` значение является строкой.

Критерии проверки:

- история используется как стек;
- отменяется только последнее неотменённое добавление;
- пустая отмена обработана явно;
- время `O(N)`, память `O(N)` для результата.

## Easy 2. Корректные скобки в формуле

Проверьте правильность круглых, квадратных и фигурных скобок. Остальные символы игнорируются.

```python
def brackets_are_valid(text: str) -> bool:
    ...
```

Примеры:

```python
assert brackets_are_valid("revenue - (tax + fee[0])") is True
assert brackets_are_valid("([{}])") is True
assert brackets_are_valid("([)]") is False
assert brackets_are_valid("amount)") is False
```

Ограничения:

- `0 <= len(text) <= 1_000_000`;
- использовать стек открывающих скобок;
- регулярные выражения не требуются.

Критерии проверки:

- закрывающая скобка проверяет вершину стека;
- лишняя закрывающая скобка сразу даёт `False`;
- после обхода стек должен быть пуст;
- время `O(N)`, память `O(N)` в худшем случае.

## Easy 3. Обслуживание очереди

События имеют вид `("arrive", request_id)` или `("serve", None)`. При `arrive` заявка становится в конец очереди. При `serve` обслуживается первая заявка; если очередь пуста, событие пропускается.

```python
def served_requests(
    events: list[tuple[str, str | None]],
) -> list[str]:
    ...
```

Пример:

```python
events = [
    ("arrive", "r-1"),
    ("arrive", "r-2"),
    ("serve", None),
    ("arrive", "r-3"),
    ("serve", None),
]
assert served_requests(events) == ["r-1", "r-2"]
```

Ограничения:

- `0 <= len(events) <= 200_000`;
- использовать `collections.deque`;
- `list.pop(0)` запрещён.

Критерии проверки:

- порядок обслуживания FIFO;
- пустая очередь обработана явно;
- ожидаемое время `O(N)`.

## Medium 1. Циклическая обработка задач

У каждой задачи есть `id` и положительное число требуемых шагов `steps`. За один раунд обработчик выполняет один шаг первой задачи. Незавершённая задача возвращается в конец очереди, завершённая записывается в результат.

```python
def completion_order(tasks: list[dict]) -> list[str]:
    ...
```

Исходные словари изменять нельзя.

Пример:

```python
tasks = [
    {"id": "a", "steps": 1},
    {"id": "b", "steps": 3},
    {"id": "c", "steps": 2},
]
assert completion_order(tasks) == ["a", "c", "b"]
```

Ограничения:

- `0 <= len(tasks) <= 100_000`;
- сумма `steps` не превосходит `1_000_000`;
- идентификаторы уникальны;
- использовать очередь.

Критерии проверки:

- каждый раунд берёт задачу слева;
- незавершённая задача добавляется справа;
- исходные записи не изменяются;
- время `O(sum(steps))`, память `O(N)`.

## Medium 2. Скользящее среднее нагрузки

Для каждого полного окна длины `window` верните среднее значение.

```python
def moving_average(values: list[float], window: int) -> list[float]:
    ...
```

Пример:

```python
assert moving_average([10, 20, 30, 50], 3) == [20.0, 100 / 3]
```

Ограничения:

- `1 <= window <= len(values) <= 500_000`;
- пересчитывать сумму каждого окна с нуля запрещено;
- использовать `deque` и текущую сумму.

Критерии проверки:

- входящий элемент прибавляется один раз;
- уходящий элемент вычитается один раз;
- время `O(N)`, дополнительная память `O(window)`;
- исходный список не изменяется.

## Hard 1. Максимум нагрузки в окне

Для каждого полного окна длины `window` верните максимальное значение за `O(N)`.

```python
def sliding_maximum(values: list[int], window: int) -> list[int]:
    ...
```

Используйте монотонную очередь индексов. Значения по этим индексам должны идти по невозрастанию. Перед добавлением нового элемента удаляйте справа индексы с меньшими или равными значениями, а слева — индексы, покинувшие окно.

Пример:

```python
assert sliding_maximum([1, 3, -1, -3, 5, 3, 6, 7], 3) == [
    3, 3, 5, 5, 6, 7
]
```

Ограничения:

- `1 <= window <= len(values) <= 1_000_000`;
- `max(values[i:i + window])` для каждого окна запрещён;
- каждый индекс добавляется и удаляется не более одного раза с каждой стороны.

Критерии проверки:

- слева всегда находится индекс максимума текущего окна;
- устаревшие индексы удаляются до чтения максимума;
- очередь хранит индексы, а не только значения;
- время `O(N)`, память `O(window)`.
