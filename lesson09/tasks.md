## Easy 1. Проверка диапазона

Напишите фабрику `make_between(low, high)`. Она возвращает функцию, которая получает целое число и проверяет, находится ли оно между `low` и `high` включительно.

Если `low > high`, сама фабрика сразу поднимает `ValueError`, не дожидаясь вызова возвращаемой функции. Равные границы допустимы.

```python
from collections.abc import Callable

def make_between(low: int, high: int) -> Callable[[int], bool]:
    ...
```

Примеры:

```python
is_small = make_between(0, 10)
is_negative = make_between(-5, -1)
assert is_small(0) is True
assert is_small(10) is True
assert is_small(11) is False
assert is_negative(-2) is True
assert is_negative(0) is False
assert is_small(5) is True
assert make_between(3, 3)(3) is True
assert make_between(3, 3)(2) is False

try:
    make_between(10, 0)
except ValueError:
    pass
else:
    raise AssertionError("Неверные границы нужно отклонить при создании проверки")
```

Ограничения: аргументы фабрики и предиката — целые числа по модулю до 10⁹; до 100 000 проверок.

Критерии: результат — `bool`; обе границы включены; настройки разных предикатов независимы. Время и дополнительная память создания и одного вызова — `O(1)`.

## Easy 2. Накопитель с ограничением

Напишите `make_accumulator(initial)`. Она возвращает функцию `add(delta)`, которая прибавляет `delta` к текущему значению и возвращает получившееся значение. Состояние изначально равно `initial`.

Текущее значение должно оставаться в пределах от 0 до 10⁹ включительно. Если прибавление вывело бы его за границы, поднимите `ValueError` **без изменения состояния**. Отрицательная прибавка разрешена. Вызов с `delta == 0` позволяет получить текущее значение.

```python
from collections.abc import Callable

def make_accumulator(initial: int) -> Callable[[int], int]:
    ...
```

Примеры:

```python
add = make_accumulator(10)
other = make_accumulator(0)
assert add(5) == 15
assert other(2) == 2
assert add(-15) == 0

try:
    add(-1)
except ValueError:
    pass
else:
    raise AssertionError("Значение не должно стать отрицательным")

assert add(0) == 0
assert add(3) == 3
assert other(0) == 2

at_top = make_accumulator(10**9)
try:
    at_top(1)
except ValueError:
    pass
else:
    raise AssertionError("Верхняя граница превышена")
assert at_top(0) == 10**9
```

Ограничения: `0 <= initial <= 10⁹`, `delta` — целое число по модулю до 10⁹; до 100 000 вызовов. Начальное значение гарантированно допустимо.

Критерии: состояние сохраняется между вызовами, разные накопители независимы, отклонённое прибавление не меняет последующие результаты. Время и дополнительная память одного вызова — `O(1)`.

## Easy 3. Чистый текст результата

Напишите декоратор `strip_result`. Он вызывает исходную функцию, получает строковый результат и возвращает его без пробельных символов по краям, по правилам `str.strip()`.

Исходная функция гарантированно возвращает строку, если завершилась успешно. Передайте ей все позиционные и именованные аргументы без изменения. Вызовите её ровно один раз на вызов обёртки. Её исключения должны выходить наружу без подмены.

```python
from collections.abc import Callable

def strip_result(func: Callable) -> Callable:
    ...
```

Примеры:

```python
calls = []

@strip_result
def label(name, *, suffix=""):
    """Подпись для имени."""
    calls.append(name)
    return f"  {name}{suffix}\n"

assert label("чай", suffix="!") == "чай!"
assert label(name="хлеб") == "хлеб"
assert calls == ["чай", "хлеб"]
assert label.__name__ == "label"
assert label.__doc__ == "Подпись для имени."

@strip_result
def blank():
    return " \n\t"

assert blank() == ""
```

Ограничения: до 100 000 вызовов; длина возвращаемой строки — до 100 000 символов. Аргументы могут быть любого типа, который принимает исходная функция; сама обёртка их не проверяет и не изменяет.

Критерии: удаляются только пробельные символы по краям результата, сохраняются аргументы и сведения о функции. Дополнительное время и память — не более `O(L)` по длине результата, без учёта вызова исходной функции и передачи аргументов.

## Medium 1. Лимит попыток вызова

Напишите `call_budget(limit)` — фабрику декораторов. Полученный декоратор ограничивает число попыток вызова каждой обёрнутой функции.

```python
from collections.abc import Callable

def call_budget(limit: int) -> Callable:
    ...
```

Правила:

- если `limit < 0`, `call_budget(limit)` сразу поднимает `ValueError`;
- у каждой обёртки собственный счётчик, даже если один декоратор применили к нескольким функциям;
- первые `limit` попыток вызывают исходную функцию; попытка расходуется **перед** её вызовом;
- исключение исходной функции тоже расходует попытку и выходит наружу без подмены;
- после исчерпания лимита обёртка поднимает `RuntimeError`, не вызывая исходную функцию;
- `limit == 0` запрещает все вызовы;
- аргументы и результаты допустимых вызовов передаются без изменения.

Примеры:

```python
calls = []
limited = call_budget(2)

@limited
def divide(a, b=1):
    calls.append((a, b))
    return a / b

@limited
def total(a, *, b=0):
    return a + b

assert divide(6, b=3) == 2.0
try:
    divide(1, 0)
except ZeroDivisionError:
    pass
else:
    raise AssertionError("Исходное исключение должно выйти наружу")

try:
    divide(10, 2)
except RuntimeError:
    pass
else:
    raise AssertionError("Две попытки уже использованы")

assert calls == [(6, 3), (1, 0)]
assert total(2, b=3) == 5  # У этой обёртки свой лимит.
assert total(a=0) == 0
```

Ограничения: `limit` — целое число, `-1 <= limit <= 100 000`; число попыток — до 200 000. Исходные функции принимают только обычные синхронные вызовы. Обёртка должна сохранять имя и описание функции через `wraps`.

Критерии: лимиты независимы, неудачные вызовы учтены, запрещённые вызовы не запускают функцию. Дополнительное время и память одного вызова — `O(1)` без учёта работы функции и передачи аргументов.

## Medium 2. Последний успешный результат

Напишите декоратор `remember_last`. Он хранит результат **только последнего успешного вызова** исходной функции.

```python
from collections.abc import Callable

def remember_last(func: Callable) -> Callable:
    ...
```

Оборачиваемая функция принимает целые числа, переданные только позиционно, и возвращает целое число либо поднимает исключение. Пустой набор аргументов допустим, если его принимает исходная функция. Именованных аргументов во входных вызовах нет.

Правила:

- при первом вызове выполните исходную функцию;
- если кортеж аргументов равен кортежу последнего успешного вызова по обычному `==`, верните сохранённый результат, не вызывая функцию;
- если аргументы отличаются, вызовите функцию; после успеха сохраните новый кортеж и результат вместо прежних;
- если функция поднимает исключение, передайте именно его дальше, а прежнюю сохранённую пару оставьте без изменений;
- разные обёртки имеют независимое состояние;
- хранить результаты всех когда-либо встречавшихся наборов нельзя: это кеш одного последнего успешного вызова.

Результат или исключение для заданного кортежа определяется значениями аргументов; зависимость от времени, случайных чисел или изменяемых внешних данных не предполагается. Порядок аргументов и их число значимы: `(1, 2)`, `(2, 1)` и `(3,)` — разные кортежи, даже если функция возвращает для них одно число.

Пример:

```python
calls = []

@remember_last
def total(*values):
    calls.append(values)
    for value in values:
        if value < 0:
            raise ValueError("Отрицательный аргумент")
    return sum(values)

assert total(1, 2) == 3
assert total(1, 2) == 3
assert calls == [(1, 2)]

assert total(3) == 3
assert total(1, 2) == 3  # Старый набор уже вытеснен, функцию вызываем снова.
assert calls == [(1, 2), (3,), (1, 2)]

try:
    total(-1)
except ValueError:
    pass
else:
    raise AssertionError("Ошибка функции должна выйти наружу")

assert total(1, 2) == 3  # Неудачный вызов не вытеснил последний успешный.
assert calls == [(1, 2), (3,), (1, 2), (-1,)]
assert total() == 0
assert total() == 0
assert calls[-1] == ()
assert len(calls) == 5
```

Ограничения: до 100 000 вызовов, до 100 аргументов в каждом; аргументы по модулю не больше 10⁹. Аргументы и результаты неизменяемые; проверки их типов не требуются. Хеширование не нужно, сравнивать можно сами кортежи.

Критерии: сохранена ровно одна успешная пара, исключения не попадают в кеш, пустой набор и нулевой результат работают правильно, сведения о функции сохранены через `wraps`. Дополнительное время — `O(m)` по числу аргументов, без учёта самой функции; дополнительная память — `O(k)` для кортежа последнего успешного вызова, где `k` — его длина.
