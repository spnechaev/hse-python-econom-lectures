Порядок оставшихся цифр должен совпадать с их порядком в исходном числе. Верните результат как целое число: начальные нули в нём не сохраняются. Если ни одной цифры не осталось, верните `0`. Число `0` считайте записью из одной цифры `0`.

Преобразовывать число или отдельные цифры в строки нельзя.

```python
def keep_digit_parity(number: int, parity: int) -> int:
    ...
```

Примеры:


## Задача 2. Соседние слова разной длины

**2 балла**

Проверяются все соседние пары исходной строки. Одно слово может входить в две пары. Сохраните повторы и исходный регистр букв.

Строка содержит только буквы и пробелы. Пробелов между словами, в начале и конце строки может быть несколько. Если подходящих пар нет или слов меньше двух, верните пустой список.

```python
def different_length_neighbors(text: str) -> list[tuple[str, str]]:
    ...
```

Примеры:

```python
assert different_length_neighbors('кот кит и мы ты') == [('кит', 'и'), ('и', 'мы')]
assert different_length_neighbors('я мы кот') == [('я', 'мы'), ('мы', 'кот')]
```

## Задача 4. Ошибки без игнорируемых кодов

**3,5 балла**

Напишите функцию `count_errors(errors, ignored)`.

`errors` — список кодов ошибок в журнале, `ignored` — список кодов, которые нужно исключить из отчёта. Коды ошибок — строки.

Верните словарь: ключ — код ошибки, значение — число его вхождений в `errors`, если его нет в `ignored`. Здесь нужно учитывать все повторения в первом списке. Повторы во втором списке ничего не меняют. Значения, встречающиеся только во втором списке, в результат не включайте.

Оба списка содержат строки. Строки сравниваются точно, с учётом регистра; очищать или преобразовывать их не нужно. Порядок ключей не важен. Если после исключения ничего не осталось, верните пустой словарь.

Требование к эффективности: среднее время работы `O(n + m)`, включая подготовку данных, где `n` и `m` — длины двух входных списков. Считайте, что проверка наличия строки в словаре или множестве, добавление записи в словарь и добавление строки в множество в среднем выполняются за `O(1)`. Объяснять сложность письменно не нужно.

```python
def count_errors(errors: list[str], ignored: list[str]) -> dict[str, int]:
    ...
```

Примеры:

```python
assert count_errors(['E1', 'E2', 'E1', 'E3', 'E2'], ['E2']) == {'E1': 2, 'E3': 1}
assert count_errors(['E1', 'E1'], ['E1', 'E1']) == {}
assert count_errors(['E1', 'E1'], []) == {'E1': 2}
assert count_errors([], ['нет записей']) == {}
```
