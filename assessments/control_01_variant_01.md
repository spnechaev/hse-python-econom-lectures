Требование к эффективности: среднее время работы `O(n)`, где `n` — число записей в `purchases`. Для этой оценки сравнение и поиск/вставку строк в словарь считайте операциями постоянной стоимости. Объяснять сложность письменно не нужно.

```python
def buyers_per_product(purchases):
    ...
```

Примеры:

```python
assert buyers_per_product([
    ("Аня", "чай"),
    ("Борис", "хлеб"),
    ("Аня", "чай"),
    ("Вера", "чай"),
    ("Аня", "хлеб"),
    ("Борис", "хлеб"),
]) == {"чай": 2, "хлеб": 2}

assert buyers_per_product([("Аня", "чай"), ("Аня", "чай")]) == {"чай": 1}
assert buyers_per_product([("Аня", "чай"), ("Аня", "хлеб")]) == {"чай": 1, "хлеб": 1}
assert buyers_per_product([]) == {}
```
