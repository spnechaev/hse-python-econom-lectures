```python
def swap_digits(number: int, first: int, second: int) -> int:
    ...
```

Примеры:


**3,5 балла**

`places` — список названий занятий, на которые есть свободные места. Каждая запись соответствует одному месту: если название встречается три раза, на это занятие есть три места. `requests` — список названий занятий в порядке заявок. Каждая заявка — на одно место.

Запросы обрабатываются по порядку. Для каждого запроса верните `True`, если его удалось выполнить, и `False` в противном случае. Успешный запрос расходует одно место. Если свободных мест на указанное занятие уже нет, нужно отказать. Отказ ничего не меняет.

Исходные списки менять нельзя. Каждый вызов функции независим от предыдущих. Строки сравниваются точно, с учётом регистра.

Среднее время работы должно быть `O(n + m)`, включая предварительную обработку первого списка, где `n` — длина первого списка, `m` — число запросов. Считайте, что проверка наличия строкового ключа, получение и изменение его значения, добавление записи в словарь в среднем выполняются за `O(1)`. Объяснять сложность письменно не нужно.

```python
def book_sessions(places: list[str], requests: list[str]) -> list[bool]:
    ...
```

Примеры:

```python
assert book_sessions(['Python', 'Python', 'SQL'],
                     ['Python', 'SQL', 'Python', 'Python', 'Excel']) == [
    True, True, True, False, False,
]
assert book_sessions([], ['Python']) == [False]
assert book_sessions(['Python'], []) == []
places = ['Python']
assert book_sessions(places, ['Python', 'Python']) == [True, False]
```
